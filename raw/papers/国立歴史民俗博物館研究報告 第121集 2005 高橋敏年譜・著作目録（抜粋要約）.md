# 高橋敏年譜・著作目録（要点メモ）

## 書誌・所在

- 『国立歴史民俗博物館研究報告』第121集（2005年3月）巻末の「高橋敏年譜」（通し頁 478〜479）と「高橋敏著作目録」。高橋敏の定年退職に際して掲載されたものと見られる（掲載趣旨の記述は本 PDF にない）。

## 要点（年譜）

| 年 | 事項 |
|----|------|
| 1940年3月1日 | 静岡県下田市に生まれる |
| 1963年 | 東京教育大学文学部史学科卒業 |
| 1965年 | 同大学院文学研究科日本史学専攻修士課程修了（文学修士）。同年から静岡県内の高校教諭（清水・沼津西・稲取・富士西）、静岡県立教育研修所指導主事 |
| 1982年 | 筑波大学附属高等学校教諭 |
| 1983年 | 群馬大学教育学部助教授（1989年3月教授） |
| 1989年4月 | 国立歴史民俗博物館歴史研究部教授 |
| 1990年12月 | 『近世村落生活文化史序説―上野国原之郷村の研究』で文学博士（筑波大学） |
| 1998〜2001年 | 同館歴史研究部部長（併任） |
| 1999〜2004年 | 総合研究大学院大学文化科学研究科教授（併任） |
| 2005年3月 | 定年により国立歴史民俗博物館・総合研究大学院大学を退職 |
