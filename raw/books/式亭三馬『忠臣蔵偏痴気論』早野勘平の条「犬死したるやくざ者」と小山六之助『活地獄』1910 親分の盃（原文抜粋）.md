# 「やくざ」が人を指す用例と「親分の盃」の用例（原文抜粋）

「やくざ」が人を指す用法と、「盃」による親分子分関係の用例を探すため、NDL ラボ「次世代デジタルライブラリー」で「やくざ者」「親分の盃」「子分の盃」を全文検索した。検索対象はインターネット公開資料の OCR テキストであり、近世の版本の多くは OCR の精度が低いため、網羅的な調査ではない。

## 1. 式亭三馬『忠臣蔵偏痴気論』早野勘平の条

- 底本: 『忠臣蔵皮肉論』（饗庭篁村校訂、富山房、1912年）。NDL ID 878920。98頁（コマ60、画像で判読）。同書は『忠臣蔵皮肉論』（作者不詳）・『忠臣蔵偏痴気論』（式亭三馬）・『田舎芝居忠臣蔵』（式亭三馬）を収める。1882年刊の別版（NDL ID 878923）にも同文がある（OCR テキストによる）。
- 『仮名手本忠臣蔵』の登場人物を一人ずつ皮肉に論評する戯作で、本条は早野勘平を論じる。

> 最初鎌倉の騒動に狼狽、又候夜前六月廿九日より、今日七月朔日までうろたへ廻り、揚句の果は犬死したるやくざ者、血判させて義士の仲間へ加へしは、郷右衛門彌五郎兩人が落度なるべし。

- 「やくざ者」は、うろたえて犬死にした役立たずの男、という意味で、勘平という人物を指して用いられている。博徒を指す用法ではない。
- 同じ論評の直前に「益（やく）にも立ぬ虚財布を、懐に持て居るが馬鹿律義なり」とあり、「やく（益）に立たぬ」と「やくざ者」が同じ文脈に並ぶ。

## 2. 小山六之助『活地獄』（1910年）

- 底本: 小山六之助『活地獄』（1910年）。NDL ID 994790。コマ40（OCR テキスト。画像では未確認）。
- 監獄で知り合った不良少年が、出獄後に東京で掏摸（すり）の仲間に入る経緯を述べる箇所。

> 彼等の仲間には學校は無い、けれども親分と云ふのが有ツて、だうしても此の親分の盃を貰ツて置かないと、所謂渡り鳥と云ふ奴で、何かに付けて不都合であると云ふので、或る緣故から、横濱の箱何とか云ふ親分の部下に爲ツた

- 掏摸の世界でも、親分の「盃を貰う」ことで仲間に入り、盃を受けていない者を「渡り鳥」と呼んだ、という記述である。著者の伝聞であり、博徒の盃事の記述ではない。

## 3. 明治・大正の講談速記・小説に見える「親分子分の盃」（参考）

NDL ラボの全文検索では、次の資料に「親分子分の盃」が見える（いずれも OCR テキスト。創作・講談であり、慣行の実在の根拠には単独で使えない）。

- 『寛政力士義侠伝』（揚名舎桃李講演、1900年）: 「親分子分の盃を返して貰い申しに來たんです」
- 伊藤痴遊『侠傑伝』（1917年）: 「即ち博奕打の親分子分の盃をしたのであるが」

## 作成者の注記

- 三馬の用例は、遅くとも江戸後期には「やくざ者」が「役に立たない者」という意味で人を指していたことを示す。博徒・遊び人を指す用法の確実な初出は、本ノートの調査でも確認できなかった。
- 『忠臣蔵偏痴気論』の原刊年は、本ノートでは確認していない（一般には文化年間の刊行とされるが、出典を確認していない）。
