# 官報 昭和21〜26年 勅令101号・団体等規正令による団体指定の告示

## 調査方法と範囲

- 国立国会図書館デジタルコレクションの「官報」コレクション（1883年7月2日〜1952年4月30日を収録）を、同コレクションの検索 API で「団体等規正令」「解散団体」「勅令第百一号」「団体指定」「團体等規正令」「解散團体」の各語により検索した。各号に付された記事索引（目次）の見出しから、勅令101号（昭和21年勅令第101号「政党、協会その他の団体の結成の禁止等に関する件」）と団体等規正令（昭和24年政令第64号）による団体指定の告示を抽出した。
- 抽出した告示の所在コマの画像（IIIF）を取得し、指定された団体名と、同日の公職除去（追放）の告示に掲げられた親分・役職員名を目視で判読した。
- 価格差益規則・配給統制規則・旧日本占領地域の法人など、同じ「団体指定」の語を含む無関係の告示は除外した。
- 限界: 記事索引に見出しが立っていない告示は、この方法では拾えない。1952年1月〜4月28日（同令の失効）には、記事索引上、団体等規正令による団体指定の告示は見当たらなかった。

### 1949年6月18日の国会答弁（暴力団体18団体）との照合

- 18団体のうち17団体は、官報の告示と日付・名称が対応した。関根組（答弁では1949年6月14日）の指定告示だけは確認できなかった。1949年6月14日号の記事索引には法務府告示の見出しがない。ただし、関根組の役職員5名は1949年9月8日の第52号で追放されており、関根組がそれ以前に指定されていたことは官報からも裏づけられる。
- 国会会議録の表記のうち、「天拘党」は日本天狗党、「萩島産」は荻島組（通称荻島一家）、「久留米露店商産合」は久留米露天商組合、「香月青年壮年同志会」は香月青壮年同志会である。会議録の文字起こしの誤りとみられる。
- 答弁が「同年」とだけ述べた香月青壮年同志会の指定日は、1948年11月19日である。
- 答弁が内務省調査局時代の唯一の暴力団体とした新鋭大衆党は、1947年12月12日の内務省告示第374号で確認できた。
- 同時期に指定された猶存社・櫻会・國本社などは国家主義団体であり、答弁の暴力団体リストに入っていないことと整合する。
