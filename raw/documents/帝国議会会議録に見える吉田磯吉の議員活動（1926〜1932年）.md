# 帝国議会会議録に見える吉田磯吉の議員活動（1926〜1932年）

帝国議会会議録検索システムの API で「吉田磯吉」を検索（265 件）して得た記録のうち、人物の活動を確認できる部分を整理した。会議録は著作権法 40 条により転載できる。

## 確認できる記録

- 衆議院議員として、1925年末から1932年1月まで、本会議・委員会の名簿や議席表に「吉田磯吉君」が継続して現れる（例: 1926-01-22 本会議の議席番号「三七九 吉田磯吉君」、1932-01-21 本会議）。
- 1927年1月29日に「九州製鋼株式会社の工場等の買収代金に関する法律案」の委員に選定され、同年2〜3月の委員会に出席した（同年3月5日に辞任）。
- 提出者として、筑豊の鉄道敷設に関する建議案に名を連ねた。1927-02-19「長尾篠栗間鐵道敷設速成ニ關スル建議案」（提出者 大里廣次郞・吉田磯吉）、1930-05-06「二瀬長尾間鐵道敷設ニ關スル建議案」（提出者 大里廣次郞・吉田磯吉・岡野龍一）。請願の紹介議員としても現れる（1931-03-17 ほか）。
- 1926年3月の「議員梅田寛一君の行動に関する調査の件」委員会（衆議院）に、任意の陳述者として出席した。3月20日に中野正剛が、藤田勇が「吾〱ノ同僚代議士吉田磯吉君ト懇意ダサウデアリマス」と述べ、吉田の出席を求め、3月24日に吉田が出席した。吉田は「牧野君モ知ラナケレバ中野正剛君モ知ラヌ」と述べ、藤田との面談は新聞を見た藤田から問われただけだと説明した（原文: 「ソレダケノコトデ別ニ何モ話モナカッタノデアリマス」）。URL: https://teikokugikai-i.ndl.go.jp/txt/005110473X00919260324/16 、 https://teikokugikai-i.ndl.go.jp/txt/005110473X00719260320/20

## 注記

- 会議録の記録上は、吉田磯吉の出身選挙区・所属政党名は上の抽出範囲では確認できていない（名簿のみ）。
- 発言者としての記録は、上記 3 件の短い答弁のみである。
