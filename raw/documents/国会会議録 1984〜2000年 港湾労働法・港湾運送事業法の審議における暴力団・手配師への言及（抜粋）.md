# 要点メモ（短い引用と要約）

東北の港（塩釜・八戸・石巻・小名浜）を名指しして暴力団と荷役を論じた発言は、「塩釜+暴力団」「八戸+暴力団」「石巻+暴力団」「小名浜港+暴力団」「港湾労働+暴力団+東北」等の検索（API、2026-10-06）では見つからなかった。以下は全国の港湾労働に関する政府答弁・議員発言であり、東北との関係を読み取る手がかりとして集めた。

- 参議院社会労働委員会 1985-06-06（目黒今朝次郎議員、質疑）https://kokkai.ndl.go.jp/txt/110214410X02519850606/76 : 「港湾労働法は六大港しか対象になっていない」「六大港以外の九十三港」についても、昔のタコ部屋・暴力団という形態から見て本質は六大港と変わらないと思う、と質問した（議員の認識。六大港以外の実態の裏付けはない）。
- 衆議院運輸委員会 1984-05-11（梅田勝議員）https://kokkai.ndl.go.jp/txt/110103830X01019840511/140 : 「かつては暴力団が支配した港湾というものが、大企業が支配するというようになってきている」と述べた（議員の評価）。
- 衆議院運輸委員会 2000-05-10（運輸省の政府参考人・高橋朋敬）https://kokkai.ndl.go.jp/txt/114703830X01420000510/89 : 「戦後しばらくの間、港湾運送におきましては、規制が自由化されたこともございまして、悪質事業者が暴力的な労務手配師として、あるいは単にピンはねを行う事業者として港湾運送事業に介入していた」。昭和40年代に関係行政機関の協力で暴力団排除が徹底され、港湾労働法の制定・港湾運送事業法の改正で日雇い労働者の使用や下請が制限され、悪質事業者は姿を消したと認識している、と答えた。
- 参議院労働・社会政策委員会 2000-05-11（労働省の政府参考人・渡邊信）https://kokkai.ndl.go.jp/txt/114715285X01120000511/36 : 港湾は労働者派遣が一般的に禁止されている理由として「かつて暴力団等によります悪質ブローカーが介在した、労働力のあっせんについてそういったものが介在し、大変な弊害があった」と答えた。六大港は港湾労働法によるセンター労働者派遣があった、とも述べる。
- 参議院社会労働委員会 1988-04-28（安恒良一議員）https://kokkai.ndl.go.jp/txt/111214410X01219880428/156 : 横浜港のやみ雇用で、手配師が日給1万3千円のうち2千円をピンはねし、1千円が地元の暴力団に渡るという話を聞いた、と質問した（伝聞）。
- 参議院決算委員会 1987-10-26 / 衆議院法務委員会 1988-03-25（法務省入国管理局・熊谷直博）https://kokkai.ndl.go.jp/txt/111205206X00519880325/52 : 外国人の不法就労について、送り出し・受け入れの「手配師、ブローカーの組織化」が摘発を通じて分かってきており、「時には暴力団と絡んでいる」と答えた（外国人労働者の話であり、東北からの出稼ぎとは別の文脈）。

## 東北に関連する周辺の言及（暴力団と産業の関係ではないもの）
- 衆議院農林水産委員会 1992-05-13（鈴木俊一議員）https://kokkai.ndl.go.jp/txt/112305007X01019920513/24 : 海産物の密漁が暴力団の資金源になっていると述べ、宮城の塩釜海上保安部が摘発した高速の密漁船の例を挙げた（質問者の発言。摘発された者が暴力団員かは述べられていない）。
- 参議院法務委員会 1982-08-05（最高裁・森廣英一）https://kokkai.ndl.go.jp/txt/109615206X01519820805/13 : 1981年10月30日、仙台地方裁判所石巻支部で、競売の執行に絡み暴力団員らが入札参加者を脅迫して競売を妨害した事件があったと答えた（民事介入暴力の事例で、港湾・炭鉱とは別）。
