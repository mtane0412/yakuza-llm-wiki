# 内閣統計局『維新以後帝国統計材料彙纂』第3輯「賭博犯處分規則ニヨリ處分セラレシ者」

内閣統計局が1913年（大正2）に刊行した、維新以後の刑事被告人に関する統計集の一表である。賭博犯処分規則（1884年1月施行）により処分された者の人数を、明治17〜22年について男女別に掲げる。NDL ラボの全文検索（「賭博犯処分規則」）で所在を特定した（目次に「第六　賭博犯處分規則ニヨリ處分セラレシ者 / 26p (0051.jp2)」）。

## 所在

- NDL ID 946278、コマ51（`0051.jp2`）、原本26頁、「第六 賭博犯處分規則ニヨリ處分セラレシ者」。同頁の左に「第五 國事ニ關スル罪」の表（明治15〜21年の国事犯被告人）がある。

- 判読上の注意: 小さな数字（特に「4」「6」「8」「3」）は画像が粗く、男女別の個別値には読み違いの可能性がある。合計欄（太字）の値は男女の和と整合することを確認した（例: 明治18年 受刑者 32,156＋1,609＝33,765、被告人 34,342＋1,892＝36,234）。
- 明治22年は6月の廃止までの分とみられるが、表に説明はない（推測）。明治21・22年の被告人欄は「—」である。

## 要点

- 受刑者の最多は明治18年（1885）の33,765人であり、「約3万3千人」に近いのはこの値である。明治17年（初年）の受刑者は27,932人、被告人は30,388人。
- 被告人・受刑者とも、規則施行の全期間を通じておおむね年2.5〜3.7万人の水準である。
