# 社会教育協会『我が国に於ける国家主義団体』1935 兵庫県の団体と代表者（抜粋）

正式な書名は『我が国に於ける国家主義団体 : 国粋・皇道・日本国家・農本主義を標傍する主要団体の名称及び綱領一般』（社会教育協会、1935年）である。前半で主要団体の綱領を、後半で府県別に団体名と代表者名を一覧にしている。

## 兵庫県の欄（原本 p.19、NDL コマ 14）

ページ画像を目視で読み取った。上段が団体名、下段が人名で、同じ列に並ぶ。

| 団体名 | 人名 |
|--------|------|
| 愛國嚮導社 | 柳田威 |
| 神州靑年同盟 | 假谷孝雄 |
| 大日本拳斗會 | 嘉納健治 |
| 大日本靑年黨 | 仙田茂吉 |
| 全國前職官吏聯盟 | 廣田壽太郎 |
| 日本鶴酒藤兄弟商會（判読やや不確実） | 井口史郎 |
| 俠友會 | 大島秀吉 |
| 神石宗教靑年會 | 谷井妙光 |
| 神石殊勳會 | 大越兵藏 |
| 楠公會總本部 | 福田宏 |
| 高昭會 | 金澤淺次郎 |
| 眞砂會 | 山口登 |
| 隼隊 | 鈴木原次郎 |
| 日本金甌會 | 蔭山貞吉 |
| 日本靑年聯盟 | 内田信三郎 |

（兵庫県の欄は、このほか七生報國黨・亞細亞靑年同志會などを含む。上表は同じ段の一部である。）

## 注記

- 下段の人名が団体の代表者であることは、一覧の体裁（他府県の欄も団体名と 1 名の人名の組）からの判断である。凡例の頁は確認していない。
- 本書は団体の自己申告や新聞報道に基づく一覧と考えられ、団体の実態（構成員数・活動）は示されない。
