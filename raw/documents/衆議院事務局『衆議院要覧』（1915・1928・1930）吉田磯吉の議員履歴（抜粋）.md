# 衆議院事務局『衆議院要覧』（1915・1928・1930）吉田磯吉の議員履歴（抜粋）

衆議院事務局が、現在議員の選挙区・所属・生年・経歴を、顔写真付きで記載した要覧である。吉田磯吉の項を3つの版から抜き出した。国立国会図書館デジタルコレクションに公開されており、NDL ラボの次世代デジタルライブラリー（`https://lab.ndl.go.jp/dl/`）の全文検索で位置を特定し、画像 API で頁を確認した。

## 1. 『衆議院要覧』下巻（1915年、衆議院事務局編）

- 所在: NDL pid 1653712、コマ109、原本 p.195（「第三編　現在議員ノ履歴（よノ部）」）。画像で照合済み。
- 記載（要約。原文は旧字体）:
  - 選挙区・所属: 福岡県郡部選出、無所属団所属。身分は士族。職業は鉱山業。
  - 生年: 慶応3年5月、筑前国遠賀郡芦屋町に生まれる。
  - 経歴: 若松瓦斯株式会社重役、若松製氷株式会社監査役に挙げられる。現に若松戸畑魚市株式会社監査役、若松貯金株式会社相談役。また石炭坑山の鉱業に従事する。
- 当選回数の記載はこの頁にない。同頁の吉原正隆の項には「衆議院議員ニ当選スルコト二回」とあり、吉田には回数の欄がない。

## 2. 『衆議院要覧』昭和3年12月（乙）（1928年）

- 所在: NDL pid 1447500、コマ112、原本 p.209（「第一編　議員履歴（よノ部）」）。画像で照合済み。
- 記載: 福岡県第二区選出、立憲民政党所属、勲三等、鉱業。慶応3年5月、福岡県遠賀郡芦屋町に生まれる。若松帆船運輸株式会社、芦屋鉄道株式会社の社長となり、現に海老津炭坑株式会社社長。衆議院議員当選4回。

## 3. 『衆議院要覧』昭和5年12月（乙）（1930年）

- 所在: NDL pid 1447527、コマ110、原本 p.208。画像で照合済み。
- 記載: 福岡県第二区選出、立憲民政党所属、勲三等、鉱業。経歴は昭和3年版とほぼ同じで、現に海老津炭坑株式会社と平山炭礦株式会社の各社長。衆議院議員当選5回。

## 注記

- 3つの版の当選回数（1928年版で4回、1930年版で5回）の差は、1930年2月の第17回総選挙の当選に対応すると読める。当選した各回の選挙年は、本ノートの頁からは確定できない。同じ要覧の「議員氏名（第十二回乃至第十七回総選挙）」欄の OCR には、第12回（1915年）、第15回（1924年）、第16回（1928年）、第17回（1930年）の福岡県の欄に吉田磯吉の氏名が現れる（表の対応は画像で照合していない）。
- 1915年版の「福岡県郡部選出」は、当時の選挙区（福岡県郡部）の表記である。1928年・1930年版の「福岡県第二区」は、1925年の選挙法改正後の中選挙区制の表記である。
- 本書は議員本人の自己申告に基づく履歴と考えられ、経歴の評価や、石炭荷役・川艜・侠客としての活動への言及はない。
