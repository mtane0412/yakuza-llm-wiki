# 国会会議録 1964〜1993年 東北への広域団体の進出・系列化と極東関口一家・極東会をめぐる委員派遣報告・答弁（抜粋）

issue #54 の調査で、国会会議録検索システム API を使い、東北の地場組織が広域団体の系列に入った経緯と、平成5年版警察白書が東北での抗争の相手方として挙げる「極東関口一家」の性格を示す発言を探した。既存の [[国会会議録 1964〜2008年 東北の暴力団勢力と広域団体の進出をめぐる発言]]（raw/documents/国会会議録 1964〜2008年 東北の暴力団勢力と広域団体の進出をめぐる発言（抜粋）.md）に収録済みの発言（1964-06-09、1972-11-13、1990-10-23、1991-03-13、1991-10-18、1993-02-12、1993-04-06、1997-12-02、2008-04-17）は再掲しない。

## 検索で確認できなかったこと（記録）

- 「盛代」で検索した結果は1件で、暴力団と無関係の発言（議員名の一部）だった。盛代盛永会に言及した発言は国会会議録にない。
- 「極東関口」は1件（下記 3 の 1977-05-17）、「関口一家」は4件（うち 1947 年の1件は隠退蔵物資事件の陳情者の姓で、暴力団と無関係）だった。山形・青森での極東関口一家の抗争（1989〜1990年）に言及した発言は見つからなかった。
- 「山口組 山形」「山口組 福島県」「稲川会 青森」「住吉会 宮城」の検索結果には、2003年の山形・福島・仙台の個別事件や、2007年の宮城の抗争の経過（発生月、当事者の傘下組織名）を述べた発言はなかった。2003年の福島県警への言及は、五菱会のやみ金融事件の合同捜査本部に関するもので、抗争とは別である。
- 1972年の委員派遣報告にある「関西方面の暴力団」の福島（福島・郡山・白河地区）への進出について、組織名を挙げた発言は見つからなかった（「郡山 暴力団」12件、「白河 暴力団」5件を確認）。
- 2005年の国粋会の吸収と宮城の抗争の関係を述べた発言は見つからなかった。

## 1. 1964-09-30 衆議院 法務委員会（第46回国会閉会後 第48号、大竹太郎委員の委員派遣報告）

- 出典URL: https://kokkai.ndl.go.jp/txt/104605206X04819640930/4
- 1964年（昭和39年）8月3日から4日間、仙台・盛岡・青森で「青少年の犯罪、暴力事犯の実態調査」等を行った第三班（東北班）の報告。

> 第一に暴力事犯について申し上げますと、東北地方における暴力団関係の暴力事犯は、いわゆるなわ張り争いを原因とする凶悪な暴力事犯が少なく、反面一般市民に対する小暴力的事犯が多いことがその特色としてあげられます。また、これらの暴力団体は、団体数に比して団員数が少なく、関東、関西方面の暴力団に比べてみればいわゆる弱小団体であるといえると思います。警察当局の説明によりますと、東北地方にも関東、関西方面の暴力団の影響が徐々にあらわれてきており、宮城県、岩手県では松葉会の組織拡大活動が活発に行なわれておるようであります。暴力団の資金源については、賭博が東北各県に行なわれておりますが、最近目立ってきているのは、暴力団の上層幹部による債権取り立てであり、またそれにかこつけて恐喝等の犯罪が行なわれておるのであります。

> 暴力団対策については、特に民間側の協力を強調しておるのでありますが、官民協力しての暴力追放運動の事例として、最近岩手県水沢市において関係機関と市民が一体となって暴力追放に立ち上がり、暴力団の一掃に成功しつつあることであります。

## 2. 1974-11-14 参議院 法務委員会（第73回国会閉会後 第3号、棚辺四郎委員の委員派遣報告）

- 出典URL: https://kokkai.ndl.go.jp/txt/107315206X00319741114/5
- 1974年（昭和49年）10月14日から17日まで、福島県・山形県・秋田県で司法行政・法務行政の実情を調査した第一班の報告。「三県下」は福島・山形・秋田を指す。

> 次に、刑法犯等のうち、三県下とも暴力団関係事件が多く、広域暴力団進出による各種抗争事件が発生し、組織再編成の動きがあるなど、なお厳重な警戒と監視が続けられております。

## 3. 1977-05-13・05-17 衆議院 地方行政委員会（第80回国会 第21号・第22号、警察庁の答弁）── 極東関口一家への警視庁の一斉取締り

1977-05-13（鈴木貞敏・警察庁刑事局長）:

1977-05-17（柳館栄・警察庁刑事局保安部保安課長）:

> それから関口一家の関連のことでございますけれども、事件の概要は、被疑者〔個人名略〕三十八歳でございますけれども、暴力団極東関口一家〔組織名・個人名略〕の四代目の首領でございます。これが詐欺罪で東京拘置所に服役中であった昭和四十六年十二月ごろから同四十九年八月ごろの間に（後略）

（抜粋者注: 5月13日の答弁は「関東関口一家」、5月17日の答弁は「極東関口一家」と呼ぶ。同じ一斉取締りの事件を指しており、13日の「関東」は言い誤りか速記の誤りとみられるが、会議録の表記のまま記載した。いずれも警視庁の取締りであり、1977年当時、極東関口一家が東京都内で活動していたことを示す。）

## 4. 1993-04-27 参議院 地方行政委員会（第126回国会 第6号、有働正治議員の質問と廣瀬權・警察庁刑事局暴力団対策部長の答弁）

- 出典URL: https://kokkai.ndl.go.jp/txt/112614720X00619930427/80（質問）、https://kokkai.ndl.go.jp/txt/112614720X00619930427/81（答弁）

質問（有働正治議員）:

> 次に、指定暴力団の指定等の問題でありますけれども、東京の場合、指定暴力団指定が全体の五割ほどであります。全国平均の七割五分から見まして大きくおくれている状況にあり、これは放置できないと考えるわけであります。例えば松葉会の指定というのは茨城県警の手を離れ警視庁の手にあると聞いておりますけれども、極東会などを含めて大きな暴力団の指定がおくれている。

答弁（廣瀬權）:

> これ以外にも大規模かつ広域に活動する暴力団がありますことから、この稲川会、住吉会を指定しました後におきましても、東京都公安委員会あるいは警視庁におきましてこうした暴力団を指定すべく現在所要の作業を懸命に進めているところでございます。

## 5. 1993-09-28 参議院 地方行政委員会（第128回国会 第1号、鎌田要人委員の委員派遣報告）

- 出典URL: https://kokkai.ndl.go.jp/txt/112814720X00119930928/8
- 1993年（平成5年）9月13・14日に秋田県・岩手県を訪問した報告のうち、警察行政の項。

秋田県:

> 暴力団の現況は、いわゆる指定暴力団への寡占化が進行しておりますが、抗争事件は沈静化傾向を見せております。

岩手県:

> 暴力団の現況は、いわゆる指定暴力団への寡占化が進んではおりますが、数年前に比較して暴力団員数は二百名程度減少してきております。
