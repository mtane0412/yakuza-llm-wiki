# 神戸大学新聞記事文庫 1932年の尼崎汽船争議と山口登・1935年の兵庫県下暴力団一斉検挙（抜粋）

神戸大学の新聞記事文庫は、戦前の新聞の切抜をテーマ別に整理した資料群で、記事の翻刻（テキスト）と切抜の画像を公開している。簡易検索（`https://da.lib.kobe-u.ac.jp/da/np/search/simple/?kywd=...`）の結果は語の分かち書きで広く当たるため、各記事の IIIF マニフェスト（`https://da.lib.kobe-u.ac.jp/files/manifest/1/20000/{ID}.json`）の「翻刻」欄で語の完全一致を確かめ、引用部分は切抜の画像で照合した。

文庫の求める出典表記に従い、各記事に「『神戸大学新聞記事文庫』分類(巻-記事番号)」を付す。

## 1. 神戸新聞 1932年11月25日「今朝まで休戦成立　急転、解決の機運見ゆ」 — 海員(3-79)

- 文庫 ID 0100062723。切抜帳「海員」第3巻 記事番号79。
- 記事の内容: 尼崎汽船の乗組員の組合加入をめぐる日本海員組合と同社の争議（尼汽争議）で、会社側に「間口組」が介在して争議が尖鋭化していた。これを憂慮した人物が仲介に入り、11月25日朝までの休戦が成立した。
- 原文（画像照合）:
  > その成行きを憂慮した間口組間口伊之助氏と深き關係を有する神戸山口組山口登氏が二十四日正午日本海員組合に濱田組合長を訪れ懇談の結果、急遽大阪に赴き會社側及び間口氏等と懇談を遂げ、〔中略〕午後六時に至り現状のまゝ二十五日朝まで休戰する事に協約が成立した
  - 〔 〕内は本ノートでの省略。文庫の翻刻は新字体で、引用は画像により旧字体に直した。
- 同じ記事は、前記の山口氏・間口氏・尼汽営業部長が神戸市内で徹夜で協議を重ね、25日午前に濱田組合長を訪れる予定と伝える。

## 2. 大阪毎日新聞 1932年11月25日「けふ勞資會見　神戸の山口氏調停に乘出す　或は急轉解決か」 — 海員(3-77)

- 文庫 ID 0100117056。切抜帳「海員」第3巻 記事番号77。
- 原文（画像照合）:
  > 尼崎汽船の爭議について神戸の有力者山口爲一氏は廿四日午前海員組合本部で濱田組合長と調停斡旋に關して懇談しさらに同日午後大阪の海員組合川口支部に片山、橫川兩支部長を訪ひ懇談の結果、遂に勞資は尖鋭化せる對立を廿五日午前まで休止を約し
- 「爲一」には「ため」とルビがある（画像で確認）。神戸新聞が「神戸山口組山口登氏」と記す人物と同じ場面・同じ役回りの人物を、大阪毎日新聞は「山口爲一」と記す。

## 3. 神戸又新日報 1935年7月1日「斷乎一掃を期し更に檢擧の手伸ぶ　檢擧者は五百餘名に達し一方各署で取調べ」 — 犯罪,刑務所および免囚保護(6-67)

- 文庫 ID 0100281217。
- 記事の内容: 「今暁三時を期して」兵庫県下で一斉に行われた「暴力團檢擧」で、午前9時すぎまでに502名、正午までに県下26署で515名を検挙したと報じ（文庫の翻刻は「午後九時」とするが、画像では「午前九時」。夕刊か朝刊かは切抜からは分からず、検挙の日は1935年6月30日または7月1日）、各署の主な検挙者を列挙する。県刑事課は「みなと神戸から凡ゆる暴力團を一掃する」方針とされる。
- 該当箇所（画像照合）: 相生橋署の検挙者のうち 1 名に「（山口組配下）」と付記がある。
  > ▲恐喝、神戸區中山手通〔番地・氏名略〕（山口組配下）
  - 検挙者の氏名・住所は、私人の個人情報であるため本ノートでは省略した。
- 同じ記事は、三草組・中山組・鴻池組などの「親分」「幹部」の検挙も列挙する。
