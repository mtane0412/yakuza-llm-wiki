# 細谷十太夫と衝撃隊（鴉組）をめぐる辞典・Web記事・文献書誌（抜粋要約）

戊辰戦争で仙台藩士の細谷十太夫（直英）が組織した衝撃隊（通称「鴉組」「烏組」）に博徒・侠客が加わったとする記述を、辞典・Web 記事・書誌から集めた。**数値・表現は Web 取得ツールが返した要約に基づく。逐語の照合はしていない**ため、確定的な引用には原典で確認すること。

## 1. コトバンク「細谷十太夫」（デジタル版 日本人名大辞典+Plus、講談社）

- 生没年は1845年（弘化2年）〜1907年（明治40年5月6日）、没年齢は63歳と要約された。
- 「猟師や博徒に黒ずくめの服装をさせた衝撃隊を組織」し、新政府軍に「からす組」と呼ばれて恐れられたとある。
- 維新後は北海道の開拓など士族授産事業にかかわり、晩年は仏門に入ったとある。

## 2. 武将ジャパン「細谷十太夫直英と衝撃隊（鴉組）」（2024-10-24）

- 衝撃隊は「侠客や博徒、猟師、馬方といった士分以外」の者で構成され、最大時は100名を超えたと要約された。
- 1868年5月、白河城の戦い（仙台藩など同盟側の敗戦）を見た細谷が、福島県の須賀川の女郎屋に「仙台藩細谷十太夫本陣」と掲示して兵を募り、「名のある侠客や博徒、猟師、馬方などが続々と参加」したと要約された（要約ツールの出力は地名を「須賀城」と表記した箇所があり、須賀川の誤記と思われる）。
- 約1か月半で30余戦して全勝し、新政府軍に「鴉組」と恐れられたとされる。
- 戦後は200石の加増と「武一郎」の名を受けたとされる。のち開拓使、陸軍少尉、西南戦争・日清戦争への従軍を経て、北海道幕別町に入植し、晩年に林子平の菩提寺・龍雲寺の中興の祖となったとされる。
- 記事が挙げる出典は、菊田定郷『仙台人名大辞書』と藤原相之助『奥羽戊辰戦争と仙台藩』（世良修蔵事件顛末）である。

## 3. note「最後の隠密：細谷十太夫」（須原誠）

- 衝撃隊の構成員の属性を、侠客・博徒・猟師・馬方と記す（個人名は挙がらない）。
- 福島県須賀川の女郎屋に「仙台藩細谷十太夫本陣」の看板を掲げて募り、最盛期に100名以上が集まったとする。
- 参考文献として『細谷十太夫伝記』（1955年）、小西四郎『戊辰戦争全史』（1977年）を挙げる。

## 4. Wikipedia「細谷直英」

- 生年を「天保10年（1839年）または弘化2年（1845年）」、没年を1907年5月6日（63歳または68歳）と併記する。
- 「白河城にほど近い須賀川で東北地方の大親分を含むヤクザを束ね『衝撃隊』を結成」とし、黒装束と八咫烏の文様の半纏から「鴉組」と呼ばれたと記す。降伏後に仙台藩から受けた金を隊士に分けて解散し、のち北海道開拓、日清戦争で陸軍少尉、警視庁小隊長を経て、仙台で僧になったとある。
- 記事内に出典の明示が乏しく、「大親分」の名は挙がらない。
