## 1. 仙台事件（1948〜1949年）の結末

- 国会会議録検索システム API で、参議院法務委員会の1949年1月10日〜1951年12月31日の発言のうち「仙台」を含むもの75件を確認した。仙台事件の調査結果・勧告・報告に触れた発言はなかった。同委員会は第8回・第9回国会などで「検察及び裁判の運営等に関する調査」の報告書を「未了」の報告として提出しているが（1950-11-20、1950-12-08 の会議録）、報告書本文は会議録 API に収録されていない。
- 全院・全期間（1948〜1960年）で「仙台事件」を検索すると8件で、すべて1948年12月27日・1949年1月8日・9日の会議録であった。「仙台地方検察庁」（1949〜1952年、11件）と「仙台駅前」（1946〜1955年、10件）でも、事件の結末に触れた発言はなかった。
- 参議院事務局『参議院委員会先例録』昭和37年版（1962、NDL PID 1674871、インターネット公開）の「報告又は記録の提出要求一覧表」（コマ179、【OCR のみ】）に、第3回〜第4回国会（1948年11〜12月）ごろ、法務委員会が法務総裁・国家地方警察本部長官などに、「昭和二十三年五月現在の全国の博徒的屋等の一覧表に関する件」と、仙台の顔役の事件（一覧表は人名で記載）および「福島事件」に関する件の提出を求めた記録がある。一覧表の OCR では行の区切りが崩れており、要求の日付と提出先の対応は確定できない。提出された資料の内容は未確認である。ここでの「福島事件」は1948年当時の事件を指し、1882年の福島事件ではない。
- 結論: 仙台事件の調査の結論（勧告の有無）、顔役の息子の贈賄被疑事件のその後は、Web で読める資料では確認できなかった。参議院の調査報告書（未了報告）の本文、河北新報の縮刷版、『仙台市史』通史編（近現代）、『宮城県警察史』が必要である。

## 3. 小田炭鉱事件（1954年）の判決と1949年の組合長襲撃

- 国会会議録で「小田炭鉱」（1947〜1965年）は3件で、いずれも1954年5月の質疑・答弁（既取得）であった。判決に触れた発言はなかった。「好間」（1947〜1960年、39件）・「常磐 暴力団」（1947〜1960年、5件）でも、判決と1949年の事件の記録は見つからなかった。
- 1954年5月12日の参議院本会議の田畑金光議員の質問は、「昭和二十四年の春、当時」の組合長も襲われたと述べるが、政府側の答弁はこれに触れていない（既取得の会議録）。
- NDL ラボの全文検索で「小田炭鉱」「小田炭礦」（318件）を見たが、戦前の会社・地質・鉱区の資料のみで、事件の資料はなかった（NDL ラボの収録はおおむね1950年代前半までのインターネット公開資料である）。
- Web 検索（「好間村 小田炭鉱 1954 殺害事件 判決」）でも判決は見つからなかった。
- 結論: 判決（福島地方裁判所平支部と見られる）と1949年の襲撃の詳細は未確認である。福島民報・福島民友・いわき民報の縮刷版、『いわき市史』、『福島県警察史』、刑事裁判資料が必要である。

## 4. 福島事件（1882年）と博徒

- NDL ラボで「喜多方事件」は0件、「福島事件」（604件）を「博徒|博奕|侠客|賭博|親分」で絞り込んで3件であった。
- そのうち鈴木万次郎『河野広中君小伝』（有斐閣、1883、PID 781346、インターネット公開）は、河野の祖父について「頗る任侠の風あり」、兄の広畔について「常に力士侠客を愛し」、河野自身について、若松県の官を辞したのち「交を侠客に結び長刀を帯び出没横行」したと記す（コマ5・6・15、【OCR のみ】）。いずれも1882年の福島事件より前、河野の家と若年期の記述であり、事件への博徒の関与を述べたものではない。
- 大内民恵『教育制度改革概論』（1930）の、著者の養父が福島事件で未決監につながれた「侠客肌」の人物だったという記述は、比喩的な人物評である。
- 結論: 福島事件・喜多方事件に博徒が関与したことを記す資料は、今回の検索でも見つからなかった。『福島事件高等法院公判録』（1955）、『福島県史』『喜多方市史』の本文は未取得である。
