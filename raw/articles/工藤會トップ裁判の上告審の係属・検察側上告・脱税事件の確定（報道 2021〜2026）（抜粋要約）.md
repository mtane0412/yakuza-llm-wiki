# 工藤會トップ裁判の上告審の係属・検察側上告・脱税事件の確定（報道の要点メモ）

各記事を WebFetch で取得し、本文を読んで要点をまとめた。全文は転載せず、短い引用に限る。2026年10月6日時点で、最高裁の判断を伝える報道を探した結果も記す。

## 1. 日本経済新聞「工藤会トップ実刑確定へ 上納金脱税で上告棄却」（2021年2月）
URL: https://www.nikkei.com/article/DGXZQODG189WN0Y1A210C2000000/

- 最高裁第3小法廷（宮崎裕子裁判長）は、工藤会総裁・野村悟被告（当時74歳）の上告を棄却する決定をし、懲役3年、罰金8千万円とした一、二審判決が確定することになった。決定は2月16日付と読める（取得時の要約による）。
- 一、二審判決は、2010〜14年に野村被告が上納金から得た計約8億900万円を申告せず、所得税約3億2千万円を免れたと認定した。上納金の一定割合が野村被告に分配され、個人的な支出に充てられていたとして課税対象とした。
- 「金庫番」とされた元幹部の懲役2年6月も確定する。同記事は、市民襲撃事件の公判で検察が死刑を求刑し、最終弁論が3月11日に予定されていると記す（2021年の一審）。

## 2. 共同通信「死刑判決が破棄された工藤会トップの事件 検察側が最高裁に上告」（2024-03-26、ライブドアニュースの見出し）、日本経済新聞「死刑破棄不服と検察側上告 工藤会トップ、一部無罪」（2024-03-26）
URL: https://www.nikkei.com/article/DGXZQOUF2645L0W4A320C2000000/

- 福岡高検は2024年3月26日、野村悟被告（当時77歳）に対し、一審の死刑判決を破棄して無期懲役を言い渡した3月12日の福岡高裁判決を不服として、最高裁に上告した。弁護側は判決当日に上告している。
- 高裁判決は、1998年の元漁協組合長射殺事件について、二次団体の「意思決定の在り方は不明としか言いようがない」と指摘し、実行犯との共謀を認めなかった（日経の引用）。
- 両記事とも、検察側の上告の対象として野村被告のみを挙げ、田上不美夫被告に対する検察側の上告には触れていない。

## 2a. FBS福岡放送「工藤会トップの2審の無期懲役判決で福岡高検が上告　射殺事件は無罪→1審の死刑判決を破棄」（2024-03-26 14:04、2024-04-01 更新）
URL: https://news.ntv.co.jp/n/fbs/category/society/fsd83ae5b9454f49a6b0d51271240a8a56

- PR #23 のレビュー（CodeRabbit）の指摘を受け、2026-10-06 に curl で記事 HTML を取得し、本文を確認した。
- 福岡高検は26日、一審の死刑判決を破棄して無期懲役を言い渡した二審判決を不服として、最高裁に上告した。
- 本文は「福岡高検は田上被告についても上告しています」と記す。
- 福岡高検の小池隆次席検事は「判決内容を十分検討した結果、上告理由（判例違反）があると判断した」とのコメントを発表した。
- 「2人の弁護側は判決を不服として即日上告しています」と記す。
- 日経・共同（上記2）が野村被告のみを挙げるのに対し、FBS は田上被告についても検察側が上告したと報じる。両者は矛盾するというより、日経・共同が田上被告に触れていないものとみられる。

## 4. 共同通信「工藤会元トップへの課税適法 上納金巡り５億円超、福岡」（2026-09-30、デイリースポーツ online 掲載）
URL: https://www.daily.co.jp/society/national/2026/09/30/0020877479.shtml （同内容: Yahoo!ニュース、熊本日日新聞、山陰中央新報、新潟日報ほか）

- 野村悟被告（79）を「二審無期懲役、上告中」と記す。
- 野村被告が約5億4千万円の課税処分の取り消しを求めた訴訟で、福岡地裁（能登謙太郎裁判長）は2026年9月30日、請求を棄却した。
- 記事は、野村被告が上納金の自身の取り分に関する脱税で「所得税法違反罪で実刑判決が確定していた」と記す。
- 訴訟記録によれば、野村被告は2014年までの7年分で13億円余りの所得を申告しなかったとして、2015年に小倉税務署から重加算税を含め約7億3千万円の追徴課税（更正処分）を受け、国税不服審判所への審査請求は2023年に棄却されていた。

## 5. 暴力団ニュース（yakuza-news.jp）「工藤會元総裁・野村悟被告の課税処分取り消し請求を棄却…」（2026-09-30）

- 上記4と同内容で、野村被告を「二審無期懲役、上告中」と記す。報道機関の明記はない二次まとめサイトのため、補助的に参照するにとどめる。

## 2026年10月6日時点の確認結果

- 最高裁が野村被告・田上被告の上告審について判断（上告棄却・破棄など）を示したという報道は、日本語・英語の Web 検索（2026-10-06 実施）では見つからなかった。
- 2026年9月30日の共同通信配信記事が「上告中」と記すのが、確認できた最新の報道である。
- 裁判所の裁判例検索では、原審事件番号「令和3(う)273」を原審とする最高裁判例は掲載されていなかった（2026-10-06 確認）。
- 検索結果の見出し（福岡TNC 2025-06-20・2026-06-18、NHK ほか）には、工藤會系の別の幹部について最高裁が上告を棄却し無期懲役が確定するとの報道があるが、野村被告・田上被告の事件ではない（本文は未読）。

## ソースの偏り・限界

- 報道であり、判決文・決定書ではない。日経の脱税事件の記事は有料記事の冒頭の要約に依る。
- 脱税事件の確定日について、一審判決（2021年8月24日）の「確定裁判」欄は「令和３年３月１４日確定」と記す（raw/documents の福岡地裁判決の抜粋参照）。日経の「2月16日付の決定」との差は、上告棄却決定後の異議申立て期間等によるとみられるが、確認していない。
