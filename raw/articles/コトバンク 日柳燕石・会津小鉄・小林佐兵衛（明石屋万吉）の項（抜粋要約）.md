# コトバンク 日柳燕石・会津小鉄・小林佐兵衛（明石屋万吉）の項（抜粋要約）

上方・西国（讃岐・京都・大坂）の幕末の博徒・侠客 3 人について、コトバンク収録の各辞典の記述を比較できるように整理した。辞典ごとに用語（「博徒」「侠客」「勤王家」）の選び方が異なる点に注意が必要である。

## 1. 日柳燕石（くさなぎ えんせき、1817〜1868）

| 辞典 | 要点 |
|------|------|
| デジタル大辞泉 | 幕末の勤王家。讃岐の人。名は政章、通称加島屋長次郎。「勤王の博徒として志士をかくまい、投獄された」。戊辰戦争に従軍中、柏崎で病死 |
| 精選版 日本国語大辞典 | 「幕末の勤王の志士」。土佐・長州の志士の尊王攘夷運動を援助し、のち戊辰戦争に加わる。詩文・書画にすぐれた。文化14〜慶応4年（1817〜68） |
| 日本大百科全書（橋詰茂） | 讃岐国那珂郡榎井村（現・香川県仲多度郡琴平町）出身。通称加島屋長二郎。叔父石崎青崗、琴平の宮医三井雪航に学ぶ。「任侠の士（博徒の親分）であったが、のち藩政を批判し勤皇精神をもつに至る」。居宅「呑象楼」に吉田松陰・桂小五郎・久坂玄瑞・中岡慎太郎らが交流。高杉晋作をかくまい逃亡させた罪で1865年（慶応元年）投獄。出獄後、北越征討の大総督仁和寺宮の日誌方として従軍し、越後柏崎の陣中で病死 |
| 改訂新版 世界大百科事典（井上勝生） | 讃岐国琴平の質商・地主の加島屋に生まれる。「詩文を学び，のち博徒の長となる」。京坂を遊歴して高杉晋作・木戸孝允・中岡慎太郎らと交際し、自邸に庇護した。高杉潜匿のゆえに高松藩に捕らわれ、1868年赦免。会津征討軍越後口総督仁和寺宮に書記役として従い、柏崎で病没 |
| デジタル版 日本人名大辞典+Plus | 「幕末の博徒,尊攘運動家,漢詩人」。文化14年3月14日生まれ。生家は琴平の質商・地主。「博徒の顔役となり,勤王派ともまじわる」。慶応元年に高杉晋作をかくまった罪で入獄、慶応4年出獄。8月25日柏崎で病死、52歳 |
| ブリタニカ国際大百科事典 小項目事典 | 生地を「讃岐，籏岡」とする。高杉晋作らを助け高松藩に捕らえられ、明治元年出獄し戊辰戦争に参加。「博徒 (ばくと) としても有名であった」 |

- 生家が質商・地主（加島屋）であった点は、世界大百科事典と日本人名大辞典+Plus が一致して記す。博徒の親分であることと、富裕な家の出身・漢詩人であることが同一人物に併存している。
- 投獄の年は「1865年（慶応元年）」（日本大百科全書・日本人名大辞典+Plus）で一致する。出獄は1868年。

## 2. 会津小鉄（あいづの こてつ、本名 上坂仙吉、1845〜1885）

| 辞典 | 要点 |
|------|------|
| デジタル大辞泉 | ［1845〜1885］江戸末期の侠客。本名、上坂仙吉。「会津藩主松平容保が京都守護職の時、その配下に属して人夫徴集や雑用の請負に当たった」 |
| デジタル版 日本人名大辞典+Plus | 幕末〜明治時代の侠客。弘化2年生まれ。京都守護職となった会津藩主松平容保の下で「会津方軍夫を指揮」。「維新後は京都，大阪に大勢力をきずき，清水次郎長らとならび称された」。明治18年3月19日死去、41歳 |

- 両辞典とも「博徒」ではなく「侠客」の語を用いる。藩の人足（軍夫）の調達・指揮という、藩権力の下請けとしての役割が経歴の中心に置かれている。
- 出生地は両辞典とも記していない（未確認）。明治期の人名辞書は「江戸の侠客」とし、本名を「大坂仙吉」と表記する例がある（`raw/books/経済雑誌社『大日本人名辞書』1885 会津小鉄の項（原文）.md` を参照）。

## 3. 小林佐兵衛（通称 明石屋万吉、1829〜1917）

| 辞典 | 要点 |
|------|------|
| 20世紀日本人名事典 | 江戸末期・明治期の社会事業家、侠客。司馬遼太郎の小説「俄」のモデル。文政12年（1829）生まれ、大正6年（1917）8月20日没。出生地は大阪府。通称「北の赤万」。「早くから俠客として立ち、幕末には大坂警備を担当していた一柳対馬守の要請で捕吏頭となるが、禁門の変で敗れた長州藩士の逃亡を助ける」。維新後、渡辺昇大阪府知事から消防事業を委託され「北の大組頭取」。米相場で巨財を成し、小林授産所を設立して貧民の内職教授・子弟の通学援助を行った |
| デジタル版 日本人名大辞典+Plus | 明治時代の侠客。明治10年ごろ大阪府知事渡辺昇の要請で消防を請け負い、北の大組頭取となる。私財を投じて授産所をつくった。「典型的な浪速侠客」。大坂出身、89歳で死去 |

- 「明石屋万吉」という通称自体は、上記 2 辞典の本文には見えない。通称「北の赤万」のみが記されている。明石屋万吉＝小林佐兵衛の同定は、村松梢風『清水の次郎長 後篇』（1951）の「大阪でも明石屋萬吉(後の小林佐兵衞)」という記述（NDL ラボ全文検索のヒット箇所）などによる。
- 幕府側の治安機構（捕吏頭）に組み込まれつつ長州藩士の逃亡を助けたという記述は、会津藩の下で人足を指揮した会津小鉄と同様に、上方の侠客が幕末の政治勢力の双方と関係を持っていたことを示す。ただし辞典の記述であり、根拠史料名は示されていない（未確認）。

## 補足（未確認事項）

- 『黒羽藩戊辰戦史資料』（小林華平編、1918、NDL pid 953184、コマ41）の「阿見日記」に、慶応4年（1868）6月、黒羽藩が「明石屋萬吉」を平（磐城平）方面へ探索として差し出した記事がある。この人物が大坂の明石屋万吉（小林佐兵衛）と同一人物かどうかは確認できていない。同名の別人の可能性がある。
