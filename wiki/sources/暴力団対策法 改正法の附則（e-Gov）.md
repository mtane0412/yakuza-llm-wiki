# 暴力団対策法 改正法の附則（e-Gov）

[[暴力団対策法]]の現行条文（e-Gov 法令 API の XML）に収録された改正法の附則のうち、法本体を改正した5件（1993・1997・2004・2008・2012年）の附則を抜粋した。各改正の法律番号・公布日・施行期日の定め方・経過措置が分かる。補足として、2008年改正の一部施行を伝える茨城県警察本部長通達（2008年5月30日）の冒頭も raw に収録した。

## 書誌情報

- 平成5年5月12日法律第41号、平成9年6月6日法律第70号、平成16年4月28日法律第38号、平成20年5月2日法律第28号、平成24年8月1日法律第53号の附則。
- 取得日 2026年10月6日。e-Gov の改正履歴 API は2016年以降の版しか返さなかったため、附則で確認した。

## 主要な論点

- 1993年改正（平成5年法律第41号）は、公布から3月以内の政令で定める日に施行（別表に2号を加える改正は公布日施行）。
- 1997年改正（平成9年法律第70号）は、公布から6月以内の政令で定める日に施行（別表の改正は公布日施行）。
- 2004年改正（平成16年法律第38号）は、公布の日（2004年4月28日）から施行。経過措置で、改正後の15条の2・15条の3は施行後に発生した暴力行為に適用するとされた。提案理由説明（[[国会会議録 1993〜2008年 暴力団対策法改正の審議]]）と合わせると、15条の2・15条の3が対立抗争等に係る代表者等の損害賠償責任の規定であったとみられる。
- 2008年改正（平成20年法律第28号）は、公布の日（2008年5月2日）施行を原則とし、9条（暴力的要求行為）の改正、第4章に2節を加える改正などは公布から3月以内の政令で定める日の施行とされた。経過措置で、改正後の31条の2は施行後の侵害行為に適用するとされた。茨城県警察本部長通達は、代表者等の損害賠償責任と暴力排除活動の促進の規定が公布日から施行されたと記す。
- 2012年改正（平成24年法律第53号）は、公布から3月以内の政令で定める日の施行を原則とし、第2条の規定等は6月以内の政令で定める日とされた。

## 新たに得られた事実

- 2004年改正の施行日が2004年4月28日（公布日）であること。これまで本 wiki では公布日のみ判明していた。
- 2008年改正の法律番号（平成20年法律第28号）と公布日（2008年5月2日）。
- 2012年改正の法律番号（平成24年法律第53号）と公布日（2012年8月1日）。

## 既存 wiki との矛盾・補強

- [[暴力団対策法 条文（e-Gov 現行）]]の raw 冒頭の注（改正年の照合）を、附則の原文で補強する。
- 2004年11月12日の最高裁判決（[[最高裁判所第二小法廷 平成16年11月12日判決（暴力団組長の使用者責任）|最高裁H16]]）が参照法条に挙げる15条の2は、同年4月の改正で設けられた代表者等の賠償責任の規定と考えられる。ただし判決は民法715条に基づく使用者責任の判断であり、15条の2を直接適用したかは判示事項からは分からない。

## ソースの偏り・限界

> [!bias]
> 附則は施行期日の定め方を示すだけで、政令で定めた具体的な施行日や改正内容は分からない。2008年改正の「3月以内の政令で定める日」の具体的な日付は、施行期日を定める政令を取得できず、未確認である。
