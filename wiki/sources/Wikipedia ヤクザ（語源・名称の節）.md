# Wikipedia ヤクザ（語源・名称の節）

「ヤクザ」の語源について、通説（賭博用語の八九三説）と複数の異説を併記する百科事典項目である。脚注の出典が明示されない箇所が多く、学術的な論証は示されない。語源の「言い伝え」を整理した素材として使う。

## 書誌情報

ウィキペディア日本語版「ヤクザ」の「語源」「変遷」「名称」の節。MediaWiki API で取得した本文を通読した。CC BY-SA 4.0。

## 主要な論点

- 賭博用語が語源とする説が通説である。『嬉遊笑覧』（喜多村信節）が『渭浜庵随筆』を出典とし、宝暦5年（1755）序の新井白蛾『牛馬問』にも同一文章があり、白蛾の亡父が「ヤクザ」を新言葉の一つとして語ったことが記される、とする。
- おいちょかぶ（三枚がるた）の8・9・3（合計20で最低の得点）が転訛したとする説（八九三説）。異説に、傾き者を「役者のような」と言ったことからとする説、「役戯れ」説、「役座」説（飯干晃一）、儒教の悪数説、博徒の三役の隠語説がある。
- 的屋について、飯干晃一の説として、武士が大道で射的屋をしたことから「的屋」になったとする説を紹介する。
- 江戸時代までは屋号が多く、一家を名乗るのは明治・大正期に多い。1884年の賭博犯処分規則への対策として、博徒の多くが土木建築請負の看板を上げ、「組」を名乗るようになったとする。

## 新たに得られた事実

- 「ヤクザ」の語が、18世紀半ばの文献（『牛馬問』の序は宝暦5年）に新言葉として現れるとされること（Wikipedia による紹介。原典は未確認）。

## 既存 wiki との矛盾・補強

- [[ヤクザ（呼称と語源）]]ページの根拠。「かぶき者起源説」と「八九三説」は、語源説の中で別の異説（「役者のような」）として、かぶき者に結びつけられる。ただし、語源と、集団としての起源は別の問題である。
