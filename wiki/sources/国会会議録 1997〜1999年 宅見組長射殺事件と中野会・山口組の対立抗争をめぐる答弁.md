# 国会会議録 1997〜1999年 宅見組長射殺事件と中野会・山口組の対立抗争をめぐる答弁

1997年8月の山口組若頭射殺事件について、警察庁が国会で述べた事実を抜き出したものである。事件発生日、山口組による中野会会長の絶縁処分、対立抗争の件数と検挙状況、暴力団対策法第15条（対立抗争時の事務所使用制限）の適用問題、1999年時点の警察の事件認識が得られる。

## 書誌情報

国会会議録検索システム API で「中野会」「宅見」「宅見組」「山口組 若頭 射殺」を検索した（2026-10-06）。「宅見勝」では1件もヒットしない。警察庁は人名を出さず、「宅見組の組長」「山口組の若頭」と呼ぶ。「中野会」の20件のうち、同音の議員名（中野寛成）を除く関係発言は7件、「宅見組」の関係発言は4件である。発言URLは raw を参照。

## 主要な論点

- **事件日**: 警察庁刑事局長は1997年12月4日の参議院地方行政委員会で、「八月二十八日」に神戸市内のホテルで、山口組の「ナンバーツー」の若頭にあたる「宅見組の組長」が射殺されたと答弁した。
- **絶縁**: 同じ答弁で、山口組は「九月三日に中野会の会長を絶縁処分」したと述べた。12月2日の衆議院地方行政委員会では、質問者（春名直章議員）が「九月四日に中野会を破門から絶縁処分にしたという報道」を挙げ、刑事局長が「そのように認識をいたしております」と答えた。
- **絶縁と暴対法の関係**: 刑事局長は、絶縁は「山口組内部における一つの事実行為」であり、暴対法の適用の可否は、中野会員がなお指定暴力団山口組の組員と考えられるか、新たな指定の実態があるかという「事実認定の問題」だと述べた。また、改正第15条の前提である「一の指定暴力団等に所属する指定暴力団員の集団の相互間」の対立は、この件では指定暴力団内部の対立であると述べた（1997-12-02）。
- **抗争の規模（1997-12-04）**: 刑事局長は、中野会会長の絶縁を契機に対立抗争事件が32件発生し、山口組に対し7,060か所の捜索、4,140人の検挙、けん銃101丁の押収を行ったと述べた。対立抗争32件のうち7件で16人を検挙し、そのうち6件は「宅見組傘下の組員」によるものだった。
- **事務所使用制限の仮処分（1997-12-02）**: 刑事局長は、神戸地裁が中野会本部事務所の使用を制限した仮処分は、「宅見組と思われる組員等」から中野会に「あまたたび攻撃がなされている」ことを前提に、付近住民の生命・身体の危険を認定して行われたと説明した。他方の組の事務所は攻撃を受けていないと述べた。
- **警察の捜査姿勢**: 警察庁長官は、「宅見組長射殺事件発生以来、本事件の解決へ向けまして鋭意捜査を進める」と述べた（1997-12-02）。
- **1999年の警察の認識**: 警察庁刑事局長は1999年6月8日の参議院法務委員会で、「平成九年八月には、中野会傘下組織構成員十数名が共謀しまして、白昼神戸市内のホテルにおいて山口組の若頭を射殺した」、「たまたま居合わせたお医者様が巻き添えになり射殺された」と述べた。
- **質問者の発言（1998-09-17）**: 参議院外交・防衛委員会で、佐藤道夫議員（質問者）が、「宅見組組長の射殺事件、その犯人の中野会の会長らが、これが犯人だと言われておりますけれども、ソウルのマンションで怪死した」と報道されていると発言した。政府答弁ではなく、当該部分は犯罪人引渡し条約の必要性を述べる文脈の前置きである。

## 新たに得られた事実

- 事件日は1997年8月28日（警察庁刑事局長答弁）。
- 山口組による中野会会長の絶縁は1997年9月3日（警察庁刑事局長答弁。報道は9月4日）。
- 事件後の対立抗争は、1997年12月時点で32件（白書は年末で35件）。
- 1999年6月の時点で、警察は「中野会傘下組織構成員十数名の共謀」による犯行と国会で述べていた。

## 既存 wiki との矛盾・補強

- [[宅見勝若頭射殺事件]]の事件日は、溝口が8月29日、報道要約が8月28日とし食い違っていた。警察庁答弁は8月28日であり、公的記録としては8月28日を採る根拠になる。
- 1999年3月の「警察が中野会の犯行と断定」（溝口）は、1999年6月の警察庁答弁（中野会傘下組織構成員十数名が共謀）と整合する。
- 溝口の記事では絶縁の時期が不明だった点を、警察庁答弁（1997年9月3日）で補う。ただし、平成12年版警察白書（[[警察白書 平成10〜12年版 山口組若頭射殺事件と中野会]]）は「11年7月に山口組から絶縁処分を受けた中野会」と記しており、時期の食い違いがある（同ページと[[中野会]]を参照）。
- 本ソースは暴対法第15条の運用（[[国会会議録 1993〜2008年 暴力団対策法改正の審議]]の改正経緯と併せて読む）を、実際の抗争事例で示す。

> 警察庁（刑事局長・長官）の答弁は、捜査・取締りを担う側の公式見解である。人名を出さず、動機にも触れない。中野太郎の関与や動機、宅見勝の人物像は答弁から得られない。「犯行は中野会」という認識は警察の見立てであり、判決ではない。質問者の発言（春名議員の報道引用、佐藤議員の「ソウルで怪死」）は政府の確認した事実ではない。
