# 東北の近世・近代と戦後混乱期の未確認事項の調査記録（仙台事件の結末・露天鑑札・小田炭鉱事件の判決・福島事件と博徒）

東北の前近代・近代と戦後混乱期の空白のうち、Web で読める資料では確かめられなかった項目について、どこを調べたかを記録した調査記録である。調査の途中で見つかった『参議院委員会先例録』（1962）と『河野広中君小伝』（1883）の短い記述も含む。

## 書誌情報

- 国会会議録検索システム API、NDL ラボの書籍全文検索、国立国会図書館デジタルコレクションの書誌 API、CiNii Research の OpenSearch を、2026年10月6日に用いた。

## 主要な論点

- **仙台事件の結末**: 参議院法務委員会の1949年1月10日〜1951年12月31日の「仙台」を含む発言75件に、[[仙台事件]]の結論・勧告に触れたものはなかった。同委員会の調査報告書は「未了」の報告として出されたが、本文は会議録 API に含まれない。
- **資料提出要求**: 『参議院委員会先例録』（1962）の提出要求一覧表に、1948年11〜12月ごろ、法務委員会が法務総裁らに「昭和二十三年五月現在の全国の博徒的屋等の一覧表」と、仙台の顔役の事件に関する資料を求めた記録がある。提出された資料の内容は不明である。
- **露天鑑札**: 宮城県の露天鑑札の根拠となる県令・規則は、NDL ラボと国会会議録では見つからなかった。CiNii Research で、仙台・塩竈の露店飲食店を扱う論文（森健一、1966）の書誌が見つかったが、本文は Web では読めない。
- **小田炭鉱事件**: 国会会議録（1947〜1965年）の「小田炭鉱」は1954年5月の3件のみで、判決と1949年の組合長襲撃の記録は見つからなかった。Web 検索でも判決は見つからなかった。
- **福島事件と博徒**: NDL ラボで「喜多方事件」は0件で、「福島事件」の検索結果を博徒関連語で絞り込んでも、事件への博徒の関与を記す資料はなかった。『河野広中君小伝』（1883）は、河野の兄が「常に力士侠客を愛し」、河野自身が若年期に「交を侠客に結び長刀を帯び出没横行」したと記すが、事件より前の私生活の記述である。
- **論文**: 吉崎ほか（1986）と小林文雄（2015）の本文は Web では読めない。『烏組隊長細谷十太夫』（1931）は個人送信限定である。

## 新たに得られた事実

- 1948年に参議院法務委員会が、全国の博徒・的屋の一覧表（1948年5月現在）と、仙台の事件の資料を政府に求めていたこと。
- 福島事件の指導者・河野広中が、若年期に侠客と交わったと1883年の伝記が記していること。
