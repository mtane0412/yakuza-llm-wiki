# 国会会議録 1948〜2016年 司忍・六代目山口組の分裂と山口組関係者への言及

国会会議録検索システム API で、司忍（篠田建市）・六代目山口組・神戸山口組と、山口組史の関係者（山本広・中山勝正・柳川組・岡村吾一）に触れた発言を集めた抜粋である。政府参考人の答弁は公的記録として信頼度が高いが、議員の発言は議員自身の認識・伝聞を含む。

## 書誌情報

- 政府答弁: 米田壯 警察庁刑事局組織犯罪対策部長（2007-06-13 衆議院内閣委員会）、宮本和夫 同部長（2007-11-02 同）、河野太郎 国家公安委員長（2016-04-13 参議院決算委員会）、内海倫 警察庁刑事局長（1968-03-15 衆議院予算委員会第一分科会）、於久昭臣 警察庁刑事局審議官（1985-03-08 衆議院予算委員会第三分科会）。
- 議員発言: 林百郎（1985-03-08）、田村公平（1996-05-23、1997-05-29）、内藤功（1976-08-18）、山下雄平（2016-04-13）。
- 証人: 岡村吾一（1948-04-13 衆議院不当財産取引調査特別委員会）。
- 発言 ID と URL は raw に記載した。

## 主要な論点

- 警察庁の米田部長は2007年6月13日、ボディーガードの拳銃所持について組長にも共同所持を問い、「山口組の最高幹部を連続して三人検挙」し、うち1人は「現在も刑務所に入っている。これは、現在の山口組組長の司忍こと篠田建市であります」と答弁した。（2007-06-13）
- 同答弁は、1995年（平成7年）の「藤武事件」（京都府警の警察官が抗争警戒中に暴力団と間違えられて射殺された事件）で、最高裁判決により「山口組の組長が使用者責任を問われる」ことがあったと述べ、2006年中の対立抗争事件はゼロだったと述べた。（同）
- 宮本部長は2007年11月2日、「現在の六代目山口組組長に係るけん銃の共同所持」を、ボディーガードの所持について組長の責任を共謀共同正犯として問うた事案として挙げた。（2007-11-02）
- 河野国家公安委員長は2016年4月13日、「ようやく神戸山口組の暴対法の指定ができるようになってまいりました」と述べ、「分裂したら対象から外れるというのは明らかにおかしい」として、指定の期間の見直しや団体規制の研究に言及した。（2016-04-13）
- 1985年3月8日、林百郎議員は、竹中組長の射殺後も「一和会会長の山本広」の事情聴取をしていないのかを質した。同日、警察庁の於久審議官は、竹中組二代目組長の竹中武を賭博罪で逮捕したことなどを挙げ、抗争関係で拳銃51丁（高知で14丁）を押収したと答弁した。（1985-03-08）
- 高知選出の田村公平議員は、「豪友会の会長の中山勝正」が「山口組の四代目になる予定だった」が「大阪で射殺されました」と述べた（1997年）。前年にも「山口組の四代目をやるべき中山勝正」は高知出身と述べた（1996年）。議員の認識であり、公式の評価ではない。（1996-05-23、1997-05-29）
- 内海刑事局長は1968年3月15日、「全国的な規模を持って活動をいたしております柳川組などはその最も大きなもの」で、多数の下部組織を持ち「現在も活発に活動」していると答弁した。（1968-03-15）
- 1948年4月13日、岡村吾一は辻嘉六をめぐる政治資金問題の証人として喚問され、辻から受け取った10万円は選挙費用ではなく、19歳のころから「辻嘉六の家の者」として小遣いをもらっていたと証言した。（1948-04-13）
- 内藤功議員は1976年8月18日、殖産住宅事件に関して、児玉誉士夫が「元暴力団の会長をやっていた岡村吾一」を会社側に紹介したと述べた。（1976-08-18）

## 新たに得られた事実

- **司忍と篠田建市が同一人物であることの公的記録**（警察庁の国会答弁）。あわせて、2007年6月時点で司忍が服役中であったこと、罪名が銃刀法違反の共同所持であること。
- 2004年11月12日の最高裁判決（使用者責任）の事案が、山口組組長に係るものであること。
- 神戸山口組の指定（2016年4月）の直前の、政府の問題意識。
- 1968年時点で柳川組が警察庁の答弁で最大規模の団体と名指しされていたこと。

## 既存 wiki との矛盾・補強

- [[山口組]]・[[暴対法の時代]]・[[司忍]]が記していた「篠田建市と司忍が同一人物であることは同資料に書かれていない」という未確認事項は、本ソースで解消する。
- [[最高裁判所第二小法廷 平成16年11月12日判決（暴力団組長の使用者責任）]]について、[[山口組]]の沿革は「事案が山口組に係るかは未確認」としていた。本ソースの米田答弁と、[[警察白書 平成18・22〜24・28年版と平成27年の暴力団情勢 六代目山口組・弘道会・分裂|平成18年版白書]]の「山口組組長の使用者責任を認め」た最高裁判決の記述により、1995年の京都の警察官誤射殺事件について山口組組長の使用者責任を認めた最高裁判決が存在することは確認できる。答弁と白書は判決の日付を記さないが、2003年10月の大阪高裁判決（[[警察白書 平成27年版 組織犯罪対策の歩みと展望|平成27年版白書]]）の上告審として、平成16年11月12日判決がこれに当たるとみられる。判決文の当事者・事案の照合は未了である。
- [[中山勝正]]について、議員の発言は「四代目になる予定だった」とするが、これは竹中正久が四代目に就いた事実（[[山一抗争]]）と合わない。議員の伝聞・認識として扱う。

## ソースの偏り・限界

> [!bias]
> 政府答弁は警察の立場からの説明である。議員発言（林・田村・内藤・山下）は質問の前提として述べられたもので、事実確認を経ていない。1948年の証人「岡村吾一」が北星会会長と同一人物であることは、会議録自体には書かれていない（日本語版 Wikipedia はそう扱う）。
