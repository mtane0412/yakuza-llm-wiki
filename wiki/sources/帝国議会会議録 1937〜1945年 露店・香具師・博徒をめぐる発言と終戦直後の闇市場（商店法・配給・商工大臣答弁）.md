# 帝国議会会議録 1937〜1945年 露店・香具師・博徒をめぐる発言と終戦直後の闇市場（商店法・配給・商工大臣答弁）

帝国議会会議録検索システムの API で、戦時期（1937〜1945年）の「露店」「露店商」「香具師」「博徒」等を検索した結果を整理したものである。博徒・香具師・テキヤそのものの統制を論じた議論は見つからなかった。一方、商店法案（1938年）で露店が適用除外とされた経緯、1945年1月の予算委員会で露店が配給の不公正を補う存在として語られた発言、終戦直後の闇市場をめぐる商工大臣の答弁が得られた。[[テキ屋]]が主役の資料ではなく、露店という営業形態に対する国家の扱いを示す資料である。

## 書誌情報

- 帝国議会会議録検索システム（`https://teikokugikai-i.ndl.go.jp/`）の API `/api/emp/speech` による検索（検索期間は1937年1月1日〜1945年12月31日）。検索語ごとの件数は raw ノートに示した。

## 主要な論点

- 1938年の商店法案（閉店時刻を原則午後10時とし、店員に月1回の休日を与える）の審議で、政府は露店を第18条により法律の適用外とした。ただし、露店の無制限な営業が商店との不当競争となるときは、行政官庁が終業時刻を定められる旨を設けた。(1938-03-02 衆議院 社会事業法案外二件委員会 第2号 山本芳治政府委員、1938-03-05 同第4号 成田一郎労働局長)
- 1945年1月26日の衆議院予算委員会で、作田高太郎委員（翼賛政治会）は、配給の不公正を「買出部隊ト露店ニ依ツテ……『カバー』スルヤウナ形ニナツテ居ル」と述べ、政府が「安全瓣ヲ買出部隊ト露店商人ニ求メテ居ラレルノデハナイカ」と批判した。配給統制の末期に、露店が配給を補う役割を（非公式に）果たしていたという同時代の議員の認識を示す。(1945-01-26 衆議院予算委員会 第6号 発言 63・75)
- 終戦直後の1945年12月、議員は失業者が「天下御免の露店商人に化けて」いると述べ（角猪之助）、「街路上到る處に充滿して居ります所のあの闇市場」の対策を問われた商工大臣は、闇市場が生まれた理由を物資の不足と行政力の不足に求めた（小笠原三九郎）。(1945-12-11 衆議院労働組合法案委員会 第1号、1945-12-13 同第3号、1945-12-14 貴族院予算委員会 第2号)

## 新たに得られた事実

- 露店は、1938年の商店法で営業時間規制の対象外とされ、行政官庁の裁量による終業時刻の規制のみが及んだ。露店は、商店と別の営業形態として制度上扱われていた。(1938-03-05 成田政府委員)
- 1945年1月の時点で、露店は配給統制の枠外で食料などを供給しており、国会議員が政府の配給政策の失敗の証左として言及していた。露店が敗戦後の闇市場に先立って存在していたことを示す。(1945-01-26 作田委員)
- 1945年12月の国会で、闇市場は GHQ の価格統制指令との関係で議論された。商工大臣は、統制の枠を外すことについて連合国軍司令部の了解がまだ得られていないと答弁した。(1945-12-13 小笠原商工大臣)
- 検索語「香具師」の戦時期の用例は、1945年12月5日の選挙演説を批判する比喩（「まるで香具師です」）の一件のみで、テキヤの統制を論じたものではない。「博徒」は刑法条文の引用、「親分子分」は閣僚の関係を批判する比喩（1938-02-01、宮脇長吉）で、実在の博徒団体への言及ではない。

## 既存 wiki との矛盾・補強

- [[近代 明治から敗戦まで]]の「戦時体制下」節にある、「帝国議会会議録で『博徒』『香具師』を検索したが（1937〜1945年）、該当する政策論議は取得できなかった」という記述を、検索語を増やして再確認した。博徒・香具師・テキヤそのものの統制を論じた議論が見つからなかったという結論は変わらない。
- [[闇市]]の戦後の記述について、1945年1月の時点で露店が配給の不備を補っていたという同時代の議員の発言を、戦前・戦時と戦後の連続を示す材料として補う。ただし、その露店を営んでいたのがテキヤか、一般の失業者・引揚者かは、会議録からは分からない。

## ソースの偏り・限界

> [!bias]
> 会議録は議員・政府委員の発言であり、露店商やテキヤ本人の声ではない。1945年の議員の発言は、政府批判（配給の失敗、失業者の「廃頽」）の文脈で露店を引き合いに出したもので、露店の実態を記述したものではない。

> [!bias]
> 全文検索の OCR・テキスト化に由来する誤記・欠字があり、旧字体・歴史的仮名遣いである。検索は語の一致によるため、「露店」以外の語（「夜店」「行商」「縁日」など）で述べられた発言は拾えていない。

> [!question] 要出典
> 戦時の露店商組合の統制組合化・企業整備（転廃業）に関する国会での審議は、検索語「露店」「露店商」の範囲では見つからなかった。内務省・商工省の通牒や、東京府・市の露店取締規則の改正など、行政側の資料による確認が必要である。
