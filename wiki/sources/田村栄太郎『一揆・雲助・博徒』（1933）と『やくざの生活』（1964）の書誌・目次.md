# 田村栄太郎『一揆・雲助・博徒』（1933）と『やくざの生活』（1964）の書誌・目次

1963年の書評がヤクザの起源論の「既成の諸説」に挙げる「田村」と見られる在野の近世史家・田村栄太郎の、博徒関係の主著2点の書誌と目次である。本文は確認できていない。

## 書誌情報

- 『一揆・雲助・博徒』大畑書店、1933年（NDL ID 1208508）。1935年に三笠書房（1240239）、1972年に三崎書房（12280422）から再刊。
- 『やくざの生活』雄山閣、1964年（NDL ID 3028155）。1969年版（12100461）、1981年版（13883509）がある。2026年11月に『新編 やくざの生活』が刊行予定（国立国会図書館サーチの書誌）。
- 2026-10-06 時点で、いずれも国立国会図書館デジタルコレクションの「図書館・個人送信限定」または「国立国会図書館内限定」であり、インターネット公開ではない。田村は1969年没で、著作権の保護期間内である。

## 主要な論点（目次から分かること）

- 『一揆・雲助・博徒』（1933年）の「博徒」の部は、国定忠次郎・清水の次郎長・会津の小鉄・新門辰五郎・勢力富五郎の評伝と「亂波と風呂寺」の節からなる。
- 『やくざの生活』（1964年）の「やくざ」の部は、「博奕・やくざ・高市の沿革」「江戸中心の博奕」「丁半と賭場」「旅人」「上州長脇差と貨幣経済」「親分・子分・兄弟分」「明治以降の与党・野党の博従」「てき屋のうら」の節を持つ。「裏返しやくざ列伝」は、幡随院長兵衛・中間部屋頭三之助を国定忠次・清水次郎長らと並べる。

## 新たに得られた事実

- 田村は、博奕（博徒）と高市（てき屋）の沿革を一つの節で扱い、町奴（幡随院長兵衛）をやくざの列伝に含めている。田村の起源論は、博徒・テキ屋・町奴をまとめて「やくざ」の歴史として描く構成と見られる〔推測〕。
- 「親分・子分・兄弟分」の節があり、盃事・親分子分関係の説明が含まれると推測される〔推測〕。
