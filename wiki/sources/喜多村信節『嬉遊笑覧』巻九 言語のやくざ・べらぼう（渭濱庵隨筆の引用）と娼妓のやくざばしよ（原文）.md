# 喜多村信節『嬉遊笑覧』巻九 言語のやくざ・べらぼう（渭濱庵隨筆の引用）と娼妓のやくざばしよ

江戸後期の考証随筆『嬉遊笑覧』巻九のうち、「やくざ」に関わる二箇所の原文である。「言語」の部では、『渭濱庵隨筆』（寛政元年（1789年））を引いて「やくざ」「べらぼう」を博徒の隠語に由来する「近来はやり詞」とし、「娼妓」の部では、宝暦7年（1757年）の『武野俗談』の「やくざばしよ」の用例を載せる。

## 書誌情報

- 喜多村信節『嬉遊笑覧』。成立年は raw ノートでは底本で確認されておらず、published の1830年は世界大百科事典「やくざ」の項の表記に拠る。
- 底本: 成光館出版部 1932年版 下巻（NDL ID 1123104）。「言語」見出し一覧 350頁、やくざ・べらぼうの条 364〜365頁、「娼妓」やくざばしよ 307頁。近藤活版所 1903年版 下巻（NDL ID 992505）423頁で語句を照合している。

## 主要な論点

- 巻九「言語」の見出し一覧は、末尾に「近來はやり詞　やくざ　しみたれ」と掲げる（1932年版 350頁）。
- やくざ・べらぼうの条は、『渭濱庵隨筆』（寛政元年、七十七翁葛飾素丸）を引き、「亡父」の談話として、両語が「もと博徒のことば」で常人の使うべき詞でなかったが、今は天下の常語となったと記す。語源は三枚の博奕で八・九・三が二十となり数にならないことで、「惡きことの隱語」を「八九三（ヤクザ）」と言い始めた、とする（364頁）。
- 信節自身は「このわざはしらぬ事ながらべらぼうの說は非なり」と評し、べらぼうの語源説は誤りとするが、やくざの語源説は否定していない（364〜365頁）。
- 信節は、博徒の言葉が常語に多く入っており、「一か八か」「四の五のいはず」などの数の言葉もおおかたそうであろう、と述べる（365頁）。
- 巻九「娼妓」は、宝暦7年（1757年）の馬場文耕『武野俗談』を引き、本所入江町の私娼地が「やくざばしよ」と呼ばれていたことを示す（307頁）。

## 新たに得られた事実

- 『渭濱庵隨筆』の「やくざ」の語源説は、新井白蛾『牛馬問』（1755年序）とほぼ同文である。年紀は『牛馬問』の方が34年早い。[[新井白蛾『牛馬問』宝暦5年（1755）序 ヤクザ・ベラボウの条と博奕の条（原文・近古文芸温知叢書所収）|牛馬問]]（29〜30頁）
- 「やくざばしよ」（1757年）は、「つまらない・下等な」という形容的な「やくざ」の18世紀半ばの用例である（307頁）。
- この記事での「やくざ」は「物のあしき」ものを意味し、博徒そのものを指す用例ではない（364頁）。

## 既存 wiki との矛盾・補強

> [!contradiction]
> [[Wikipedia ヤクザ（語源・名称の節）|Wikipedia ヤクザ]]は、『嬉遊笑覧』が『渭浜庵随筆』を出典とすることを先に挙げ、『牛馬問』を「同一文章がある」として後に添える。原文の年紀で並べると、『牛馬問』（1755年序）→『渭濱庵隨筆』（1789年）→『嬉遊笑覧』（1830年頃）の順であり、八九三説の確認できる最古の文献は『牛馬問』である。藤井乙男『諺語大辞典』（1910年）も、『嬉遊笑覧』所引の『渭濱庵隨筆』を引いたうえで「新井白蛾の牛馬問にも之と同様の説あり」と付記している（raw ノートによる。全文検索テキストでの確認で、画像は未確認）。

- 1932年版の割注は「葛飾丸」と読めるが、1903年版と『諺語大辞典』の引用では「葛飾素丸」であり、1932年版の脱字と見られる（raw ノートの判読による）。

## ソースの偏り・限界

> [!bias]
> 『嬉遊笑覧』は考証随筆であり、この箇所は『渭濱庵隨筆』の孫引きの形をとる。『渭濱庵隨筆』と『武野俗談』の原本・翻刻は raw ノートの作成者も確認していない。信節は三枚の勝負を「しらぬ事」と述べており、語源説の当否を自ら検証してはいない。
