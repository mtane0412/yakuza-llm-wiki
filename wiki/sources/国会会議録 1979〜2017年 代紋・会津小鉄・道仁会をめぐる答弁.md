# 国会会議録 1979〜2017年 代紋・会津小鉄・道仁会をめぐる答弁

国会会議録から、警察が「代紋」の語をどう用いたか、京都の会津小鉄（会津小鉄会）と福岡の道仁会について警察庁が述べた事実を抜き出したものである。暴力団対策法の制定・施行期（1991〜1993年）の答弁が中心である。

## 書誌情報

国会会議録検索システム API で「代紋」（1945〜1993年）、「会津小鉄」、「道仁会」（1980〜2005年）を検索した（2026-10-06）。発言ごとの URL は raw を参照。

## 主要な論点

- **代紋**: 会議録で「代紋」の語が最初に現れるのは1979年4月27日で、警察庁刑事局長が「代紋というバッジ」が捜索で出てくれば組員であることを立証できると答弁した。暴対法案の審議（1991年）では、警察庁刑事局長が、山口組・住吉会・稲川会の「我々代紋と呼んでいるもの」、すなわち組織の威力を減殺することを法の眼目と説明し、指定された暴力団は「代紋が使えない」（組の名刺を出して威力を示す行為が規制される）と述べた。
- **会津小鉄**: 警察庁は1992年2月、山口組・稲川会・住吉会に準ずる「京都に本拠を持ちます会津小鉄」などの大規模団体を重点的に指定する方針を示した。1992年12月までに「四代目会津小鉄、約一千六百人」が指定され、同団体は国家公安委員会への審査請求が棄却された後、指定の取消訴訟を提起した（1993-02-09）。
- 1995年（平成7年）の山口組と会津小鉄の対立抗争で、警察官が射殺された（いわゆる藤武事件）。遺族の使用者責任訴訟で、大阪高裁は2003年10月に山口組組長の使用者責任を認めて8,000万円の賠償を命じた（2004-04-20 答弁）。地裁では敗訴し、高裁・最高裁で勝訴したと遺族代理人の弁護士が述べた（2016-04-26）。
- 2017年3月、国家公安委員会委員長は、京都に拠点を置く指定暴力団が「後継人事をめぐって部内対立の状況にある」が、対立抗争事件には至っていないと答弁した（質問者は会津小鉄の分裂と述べた）。
- **道仁会**: 1986年12月8日以降約3か月の間に、福岡市中洲地区等の利権をめぐって「地元の暴力団道仁会と山口組系の伊豆組」が対立し、県下で61回、死者6名、負傷者13名の抗争事件が起きた（1987-12-10）。道仁会は1992年末までに暴対法で指定された15団体の一つであった（1993-02-09）。

## 新たに得られた事実

- 「代紋」の語の会議録上の初出（1979年）と、暴対法制定時の警察の用法（組織の威力を象徴する名称・標章）。
- 会津小鉄の暴対法指定（1992年、約1,600人）と取消訴訟の提起。
- 1995年の山口組と会津小鉄の抗争での警察官の殉職と、使用者責任訴訟の経過。
- 道仁会と山口組系伊豆組の抗争（1986〜1987年）の規模。

## 既存 wiki との矛盾・補強

- [[代紋]]: 既存ページは、大正・昭和初期の資料に「代紋」の語が見つからないことを記していた。本ソースで、1979年には警察の実務用語として定着していたことが確認できる（会議録は語の初出を示すものではない）。
- [[会津小鉄会]]: 既存ページの「京都」の tag が暫定だった点を、警察庁答弁（京都に本拠）で裏付ける。[[平成13年版警察白書 暴力団総合対策の推進|平成13年版白書]]の指定をめぐる損害賠償訴訟とは別に、1993年には指定の取消訴訟も提起されていた。
- [[道仁会]]: 既存ページは2006年以降の[[九州誠道会]]との抗争に限っていた。1980年代の山口組系との抗争を補う。
