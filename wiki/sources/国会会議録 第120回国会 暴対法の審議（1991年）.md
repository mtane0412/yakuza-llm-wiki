# 国会会議録 第120回国会 暴対法の審議（1991年）

暴対法案（内閣提出第90号）の1991年4月〜5月の国会審議の会議録から、提案理由説明、結社の自由・指定要件・日弁連をめぐる質疑、附帯決議、本会議の議決を原文のまま抜粋した。国会会議録検索システム API で本文を取得した（原文照合済み）。

## 書誌情報

衆議院地方行政委員会（4月18日・19日）、衆議院本会議（4月23日）、参議院地方行政委員会（4月25日・26日）、参議院本会議（5月8日）。会議録 ID と URL は raw の冒頭表を参照。

## 主要な論点

- **提案理由**: 吹田愰国家公安委員長は、「市民生活の安全と平穏が脅かされている実情にかんがみ、国民の自由と権利の侵害を防止するため」、暴力団を指定する制度を設けると説明した。内容は、指定暴力団等の指定、暴力的要求行為の禁止と中止命令・再発防止命令、被害者・事業者への援助、対立抗争時の事務所の使用制限と加入強要等の禁止、暴力追放運動推進センターの指定、の五本柱である（参院地方行政委 4月25日）。指定には国家公安委員会の確認と審査専門委員の意見を要し、聴聞・不服申立ての制度を整備すると述べた。
- **不正収益剥奪の見送り**: 警察庁の2月段階の案にあった不正収益の剥奪は、麻薬新条約の国内実施法との整合のため今回の案から見送られたと、鈴木良一警察庁長官が答弁した（衆院地方行政委 4月19日）。
- **結社の自由**: 鈴木長官は、結社の自由が重要な基本的人権であることを認めつつ、「指定を受けた暴力団は、暴力的不法行為等を行うおそれの大きい反社会的団体として法律上位置づける」にとどまり、それ以上の制約はないので憲法の結社の自由を侵すものではないと答弁した（同）。
- **指定要件（前歴者要件）**: 國松孝次刑事局長は、暴力団の構成員に占める犯罪経歴保有者の比率が一般の集団と比べて非常に高いことに着目し、「十万分の一以下」の確率で他の団体が入り込まないよう線引きをする、と答弁した（同）。
- **暴力的要求行為の限定列挙**: 制定時の9条は11項目で、警察が受理した民事介入暴力事案を分類して選んだ。将来、新たな類型が出てきた場合は法改正で追加すると刑事局長が答弁した（同）。
- **日弁連**: 國松局長は「日弁連とはかつてないぐらい密度の濃い意見の交換をいたしてきた」と答弁し、日弁連の民事介入暴力対策の委員会が暴力団の民事事件への進出に危機感を持って活動していると述べた（同）。参議院では、諫山博委員が、4月19日付で日弁連がこの法案への意見書を発表し、法案の提出の仕方に遺憾の意を表明したと指摘し、審議の拙速に抗議した（参院地方行政委 4月26日）。
- **別表と「検挙シェア」**: 暴力的不法行為等の別表には28項目の法律が並び、国家公安委員会規則で定める罪は、暴力団員の検挙人員が全体の「一五％ぐらい」を超えるものを基準とする、と刑事局長が説明した（同）。
- **議決**: 衆院地方行政委員会（4月19日）、衆院本会議（4月23日、異議なし）、参院地方行政委員会（4月26日、全会一致）、参院本会議（5月8日、総員起立で全会一致）。いずれも全会一致で可決した。
- **附帯決議**: 人権・営業の自由への配慮、質問権・立入権の慎重な運用、公開による聴聞の原則、事業者に責務と負担を求めないこと、暴追センターの運用への配慮、警察官の綱紀粛正、国会の小委員会等で政令・規則の意見を聴くこと、法案提出時期の改善（立法府の審議権への配慮）など9項目が、衆参とも付された。

## 新たに得られた事実

- 制定時の9条の暴力的要求行為は11項目であった（現行は27号）。
- 1991年3月時点で、警察庁は暴力団勢力を約3,300団体・8万8,600人、山口組約940団体・約2万6,100人、稲川会約330団体・約8,200人、住吉会約380団体・約8,100人と国会に説明した（衆院地方行政委 4月19日の國松局長の答弁。平成2年末の数値）。3団体で全体の48%であり、山口組は過去5年で勢力がほぼ倍になったと述べた。
- 衆院地方行政委員会に先立つ4月18日に法案が付託され、同日に提案理由説明があった。参院では4月25日に提案理由説明、翌日に質疑・採決が行われ、審議時間は短かった。
