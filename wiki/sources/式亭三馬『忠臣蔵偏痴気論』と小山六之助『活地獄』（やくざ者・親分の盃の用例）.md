# 式亭三馬『忠臣蔵偏痴気論』と小山六之助『活地獄』（やくざ者・親分の盃の用例）

「やくざ」が人を指す用例と、「親分の盃」の用例を NDL ラボの全文検索で探し、江戸後期の戯作と明治末の手記から抜き出したノートである。

## 書誌情報

- 式亭三馬『忠臣蔵偏痴気論』: 『忠臣蔵皮肉論』（饗庭篁村校訂、富山房、1912年、NDL ID 878920）98頁（コマ60、画像で判読）。1882年刊の別版（NDL ID 878923）にも同文がある。原刊年は raw ノートで未確認。
- 小山六之助『活地獄』（1910年、NDL ID 994790）コマ40（OCR テキスト）。

## 主要な論点

- 三馬は、『仮名手本忠臣蔵』の早野勘平を「揚句の果は犬死したるやくざ者」と評する。直前に「益（やく）にも立ぬ虚財布を、懐に持て居るが馬鹿律義なり」とあり、「やくざ者」は「役に立たない者」の意味で人を指している。
- 『活地獄』は、掏摸の仲間について「親分と云ふのが有ツて、だうしても此の親分の盃を貰ツて置かないと、所謂渡り鳥と云ふ奴で、何かに付けて不都合である」と記す。

## 新たに得られた事実

- 江戸後期には、「やくざ者」が「役に立たない者」という意味で、特定の人物を指して使われていた。これは日国の語義①（役に立たない）が人に転用された用法で、博徒・遊び人を指す語義②ではない。
- 明治末には、掏摸の集団にも「親分の盃を貰う」慣行があったと語られていた。盃による親分子分関係は、博徒・香具師に限らず、掏摸など他の集団でも語られていた。

## 既存 wiki との矛盾・補強

- [[ヤクザ（呼称と語源）]]の「人を指す用法への転化」を補う。日国が語義②の初出に挙げる『八景聞取法問』（1754年）の用例と同じく、「やくざ」が人に付く場合も、まず「役に立たない」の意味であったことを示す。
- [[盃事]]の「博徒・香具師に固有でない慣行」を補強する。

## ソースの偏り・限界

> [!bias]
> 三馬の文は戯作の論評で、語の意味を説明するものではない。『活地獄』は著者が監獄で聞いた話の伝聞であり、掏摸の慣行の実態を裏付けるものではない。全文検索は OCR の精度に左右され、近世の版本はほとんど検索できないため、より古い用例が存在する可能性がある。
