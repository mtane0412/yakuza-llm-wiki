# 国会会議録 1980〜1985年 民事介入暴力と商法改正

1981年の商法改正（総会屋への利益供与の禁止）の趣旨説明・質疑・委員長報告と、警察庁・日弁連の民事介入暴力対策に関する1980〜1985年の答弁を、会議録から原文のまま抜粋した。国会会議録検索システム API で取得した（原文照合済み）。

## 書誌情報

参議院法務委員会（1980年11月20日、1985年3月26日）、参議院決算委員会（1981年3月2日）、衆議院本会議（1981年4月17日）、衆議院法務委員会（1981年4月24日）、参議院本会議（1981年6月3日）。公布日は e-Gov 商法の附則（昭和56年法律第74号、1981年6月9日）で確認した。

## 主要な論点

- **警察庁の体制**: 1979年12月に警察庁に民事介入暴力対策センターが設置され、各都道府県警察に相談等の処理に当たる担当官が置かれた（参院法務委 1985年3月26日、上野浩靖捜査第二課長の答弁）。1981年3月2日の参院決算委員会でも、中平和水刑事局長が、警察庁と各都道府県・警察署に民事介入暴力に対応する機関を置き、日弁連・単位弁護士会も同様の仕組みを作ったと答弁している。
- **日弁連との連携**: 1980年春ごろ日弁連が独自に民事介入暴力の対策委員会を設置し、同年4月18日に警察庁幹部と日弁連幹部の第1回懇談会、10月7日に日弁連会長名での協力依頼、10月20日に実務者会議が開かれた（参院法務委 1980年11月20日、漆間英治捜査第二課長の答弁）。各単位弁護士会に被害者の救済センターを設ける方針も示された。
- **総会屋の実数**: 警察が把握する総会屋は1980年末で約5,800人、うち暴力団構成員が約1,100人、残りは暴力団と結託し、またはその支配下・影響下にある者が相当数、との答弁（衆院法務委 1981年4月24日、中平和水刑事局長）。
- **罰則**: 中平局長は、新設される商法497条により、取締役・使用人等が株主の権利の行使に関し会社の計算で財産上の利益を供与したときは「六カ月以下の懲役または三十万円以下の罰金」に処せられ、情を知って受けた者も同罪になると説明した（衆院法務委 1981年4月24日）。
- **改正の趣旨**: 法務大臣は、総会屋の排除のため「株主権の行使に関して会社がする利益の供与を禁止」し、利益の供与を受けた者は会社に返還しなければならず、会社の計算で供与した取締役等は刑罰に処すると説明した（衆院本会議 1981年4月17日）。
- **条文の構造**: 商法294条ノ2が「会社ハ何人ニ対シテモ株主ノ権利ノ行使ニ関シ財産上ノ利益ヲ供与スルコトヲ得ズ」と定め、会社側が悪いという考え方を加えた。議長の命令に従わない者の退場命令の規定も置かれた（衆院法務委 1981年4月24日、中島一郎民事局長）。
- **成立**: 参議院本会議が1981年6月3日に起立により可決した。法務委員会は附帯決議（10項目）を付した（委員長報告）。

## 新たに得られた事実

- 日弁連の民事介入暴力対策委員会は、国会答弁では1980年春の設置とされる。
- 総会屋の数と暴力団との関係に関する警察の把握（1980年末）。
- 中平刑事局長は、1978年に警察庁の科学警察研究所で行った暴力団の資金推計（1人当たり年間所得の平均を約1,000万円とする）を同じ方法で当てはめると、総会屋約5,800人で年間約580億円（1978年時点の推計は約421億円）になるが、これは単純計算であり、暴力団に流れた金額を正確には把握していないと述べた。1980年中に総会屋368人を検挙したとも答弁した（衆院法務委 1981年4月24日）。
