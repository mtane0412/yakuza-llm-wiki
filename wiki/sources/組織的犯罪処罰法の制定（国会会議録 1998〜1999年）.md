# 組織的犯罪処罰法の制定（国会会議録 1998〜1999年）

組織的犯罪対策三法案（組織的犯罪処罰法案・通信傍受法案・刑事訴訟法改正案）の趣旨説明（1998年5月8日）と、参議院での可決（1999年8月12日）の会議録、および組織的犯罪処罰法の現行条文の冒頭（目的・定義・加重処罰・犯罪収益等隠匿）を収めた。国会会議録検索システム API と e-Gov 法令 API で取得した（原文照合済み）。

## 書誌情報

- 趣旨説明: 衆議院本会議 第36号（第142回国会、1998年5月8日）、下稲葉耕吉法務大臣。
- 可決: 参議院本会議 第45号（第145回国会、1999年8月12日）。議事日程は「第百四十二回国会内閣提出、第百四十五回国会衆議院送付」と記す。
- 条文: 平成11年法律第136号（公布は1999年8月18日）。取得時点の現行条文であり、制定時の条文ではない。

## 主要な論点

- **趣旨**: 法務大臣は、暴力団等による薬物・銃器の取引や不正な権益の獲得を目的とする犯罪、宗教団体信者による大規模な凶悪事犯、法人組織を利用した詐欺商法等の経済犯罪など、「組織的な犯罪」が平穏な市民生活を脅かしていること、国連の会議や先進国首脳会議でも重要課題として取り上げられ、主要国で法整備が進んでいることを挙げた。
- **組織的犯罪処罰法案の要点**: (1)組織的な殺人等の処罰の強化、(2)マネーロンダリングの規制（犯罪収益を用いた法人等の事業経営の支配を目的とする行為や隠匿等の処罰、没収・追徴制度の拡充、疑わしい取引の届出制度の拡充、没収・追徴の国際共助）。
- **成立**: 参議院本会議で、投票総数241票（賛成142票、反対99票）で三案が可決された。通信傍受法案（いわゆる盗聴法案）をめぐって法務委員長解任決議案が提出されるなど、会議は混乱した。
- **条文**: 「団体」は共同の目的を有する多数人の継続的結合体で、目的を実現する行為が組織により反復して行われるもの（2条1項）。団体の活動として、実行するための組織により一定の罪が行われたとき、刑が加重される（3条）。犯罪収益等の隠匿は処罰される（10条）。

## 新たに得られた事実

- 組織犯罪処罰法は、暴対法のような暴力団に限定した法律ではなく、組織的犯罪一般を対象とする。法案の説明で暴力団等は例示の一つとして挙げられている。
- 公布は1999年8月18日、可決は1999年8月12日である。施行は平成12年（2000年）2月と、[[平成13年版警察白書 暴力団総合対策の推進]]が記す。
