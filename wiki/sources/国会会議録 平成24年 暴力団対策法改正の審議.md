# 国会会議録 平成24年 暴力団対策法改正の審議

2012年（平成24年）の[[暴力団対策法]]改正案について、松原仁国家公安委員会委員長の提案理由説明、北橋健治北九州市長ら参考人の陳述、警察庁の概要説明、衆議院内閣委員会の報告を、国会会議録検索システムの API から原文で取得した。国会での発言であり、一次資料である。

## 書誌情報

- 参議院先議の法案で、参議院内閣委員会で2012年6月14日に提案理由が説明され、6月19日に参考人質疑が行われた（北橋健治北九州市長、疋田淳弁護士ら3名）。衆議院内閣委員会は7月20日に提案理由を聴いて質疑・採決し、7月26日の本会議で委員長報告が行われた。
- 発言ごとの ID と URL は raw に記載した。

## 主要な論点

- 改正の柱は4つである。(1) 都道府県公安委員会が、対立抗争時に特定抗争指定暴力団等、不当要求に関連する危険な暴力行為の場合に特定危険指定暴力団等を指定し、警戒区域内の一定の行為を罰則の対象とする。(2) 国家公安委員会の認定を受けた都道府県暴力追放運動推進センターによる事務所使用差止め請求制度の導入。(3) 暴力的要求行為・準暴力的要求行為の規制強化と、縄張りに係る用心棒役務の禁止。(4) 国・地方公共団体の責務の追加と、事業者の努力義務の新設。（松原国家公安委員長、2012-06-14）
- (3) の準暴力的要求行為の項で、禁止対象に「指定暴力団等の威力を示すことを常習とする者で指定暴力団員でなくなった日から五年を経過しない者等」が追加された。これは離脱後5年間の扱いの法律上の一例である。同上（同日）
- 北橋健治北九州市長（参考人）は、福岡県に指定暴力団の本部が5つあること、2011年3月の経済界リーダー宅への手りゅう弾事件を契機に県・市・県警のトップ会議が法改正を要請したこと、2010年3月の福岡県暴排条例施行の直前に市内の学校近くで暴力団が看板を掲げて事務所を設置したことなどを述べ、北九州市に本部を置く指定暴力団が特定危険指定暴力団に該当することは明らかだと述べた。同上（2012-06-19）
- 疋田淳弁護士（参考人、日弁連民事介入暴力対策委員会の元委員長）は、事務所使用差止め制度と特定抗争指定を支持した。一方、浜田昌良議員の質問は、日弁連内に、指定の要件が「おそれ」であるため恣意的運用や結社の自由の侵害を危ぶむ意見があることを指摘した。同上（2012-06-19）
- 衆議院内閣委員会は2012年7月20日に全会一致で原案可決とし、附帯決議が付された。荒井聰議員の委員会報告による。同上（2012-07-26 本会議）
- 警察庁の政府参考人の栗生俊一氏は、「小出し」ではないかとの質問に対し、規制を一つずつ情勢に応じて検討する政府の方針を述べた。同上（2012-07-20）

## 新たに得られた事実

- 暴対法改正の審議経過（参議院先議、衆議院で全会一致）と、改正の4本柱の公式の説明。
- 特定危険指定暴力団制度が、北九州市の事業者襲撃事件への対応として強く求められたこと（地元自治体の首長が参考人として陳述）。
- 離脱後5年の準暴力的要求行為の禁止対象の追加。

## 既存 wiki との矛盾・補強

- 「2012年の暴対法改正で特定抗争指定暴力団・特定危険指定暴力団が創設された」という記述を、国会の提案理由で原文確認した。[[特定抗争指定暴力団]]
