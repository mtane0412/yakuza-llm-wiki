# 警察庁 暴力団情勢 平成26年〜令和7年 住吉会の動向

警察庁が毎年公表する「暴力団情勢」（平成26〜令和2年）と「組織犯罪の情勢」（令和3年以降）から、住吉会に関する「主要団体等の状況」の記述、指定暴力団一覧表の住吉会の欄、勢力の推移、中止命令件数などを抜き出した資料集である。警察庁による一次の公刊資料である。

## 書誌情報

- 平成26年版〜令和7年版（確定値版、2026年4月）の計12冊。各 PDF の URL は raw ファイルに記載されている。
- 平成28年版の一覧表の住吉会の行は、PDF のテキスト抽出で取得できなかった。

## 主要な論点

- **トップの二重構造**: 2014年版は住吉会の「会長」を「組織のナンバー２」と記す。一覧表の「代表する者」は西口茂男（2014〜2015年版）で、2017年9月の総裁西口茂男の死去後は関功（2017〜2021年版）、小川修（2022年版以降）である。（平成26年版、平成29年版、一覧表）
- **代目継承**: 2021年4月に「八代目会長が最高位の代表に就任し、渉外委員長を九代目会長とする代目継承」を行った。2022年5月に「代表」が死去した。（令和3年版、令和4年版）
- **本部の移転**: 一覧表の主たる事務所は2014〜2022年版が東京都港区赤坂、2023年11月の東京都公安委員会の公示で東京都新宿区の施設に変わり、2024年6月に東京地裁が使用差止仮処分命令を決定、2025年6月の公示で東京都港区（芝浦）の施設に変わった。（令和5〜7年版）
- **他団体との関係**: 2015年の山口組分裂について当初は中立だったが、2016年に会長が六代目山口組組長と会食するなど六代目山口組と関係を持つようになり、神戸山口組には「静観」の立場とされた。2019年以降、六代目山口組への時候挨拶や、六代目山口組・関東地区の団体との食事会が毎年のように記される。（平成28年版、令和元〜6年版）
- **取締り指標**: 2025年の中止命令は団体別で住吉会が196件と最多（六代目山口組153件、稲川会138件）。2025年の暴力団からの拳銃押収27丁のうち住吉会が8丁（29.6％）。（令和7年版）

## 新たに得られた事実

| 年 | 出来事（警察庁の記述） |
|----|--------|
| 2014年 | 1月に埼玉県内の住吉会関連施設で新年会。4・5月に会長の継承人事と「総務長」「総局長」の新設を含む新役員人事、5月に新会長の襲名式 |
| 2015年 | 6月、会長が公職選挙法違反（買収）で検挙（同月起訴） |
| 2016年 | 4月に「組織統括長」を新設。会長が六代目山口組組長と会食 |
| 2017年 | 9月、総裁西口茂男の死去に伴う葬儀。埼玉県内の関連施設で会長関功以下約300人が出席して「偲ぶ会」 |
| 2021年 | 4月、八代目会長が最高位の代表に、渉外委員長が九代目会長に就任 |
| 2022年 | 5月に死去した代表の葬儀。埼玉県内の関連施設で会長以下約350人が出席して四十九日法要 |
| 2023年 | 6月に役職改編（委員長補佐を廃止し中央委員を新設、副会長を組織委員に改称）。9月に会長小川修を兄・親とする盃式。11月に主たる事務所を新宿区の施設とする公示 |
| 2024年 | 6月、新宿区の主たる事務所に東京地裁が使用差止仮処分命令。10月に盃式 |
| 2025年 | 6月、主たる事務所を港区の施設とする公示。6月17日に12回目の指定。10月に会長小川修を親とする親子盃式 |

- 勢力範囲は1都1道1府15県（2014〜2021年版）から1都1道1府14県（2022〜2023年版）、1都1道14県（2024〜2025年版）に縮小した。
- 構成員は2006〜2009年末の6,100人から2025年末の2,100人へ、準構成員等を含む計は12,400人から3,100人へ減少した。2025年末の構成員は全暴力団の22.3％で、六代目山口組に次ぐ2位である。
- 中止命令は2014年に315件、2015年に277件であった。
- 検挙事例として、2020年の持続化給付金の不正受給（2025年8月に詐欺罪で逮捕、青森）、実態のない老人ホームの入居申込金をめぐる詐欺、労働者派遣法違反が掲載されている。

## 既存 wiki との矛盾・補強

- 本資料の構成員数は[[警察統計 指定暴力団の構成員数の推移（稲川会・住吉会・山口組）]]の住吉会の数値と一致する。
- [[Wikipedia 住吉会（3回目取り込み）]]の歴代首領（八代目 関功、九代目 小川修）は、令和3年版の「八代目会長」「九代目会長」の記述と、一覧表の代表する者の推移を照合すると整合する（照合による推定。警察庁の記述は人物名を伴わない）。

> [!contradiction]
> 新宿区の主たる事務所の使用差止仮処分命令について、令和6年版は「令和６年６月」とし、[[Wikipedia 住吉会（3回目取り込み）]]（毎日新聞 2024-07-19 を出典とする）は「2024年7月18日」とする。決定日と報道日の差か、記載の誤りかは未確認である。

## ソースの偏り・限界

> [!bias]
> 警察庁の把握に基づく概数と、警察の視点による組織動向の記述である。構成員の認定基準は公表されていない。人事の記述は役職名のみで人物名を伴わないことが多く、人物の特定には一覧表との照合が必要である。代表する者「小川 修」は報道や Wikipedia では「小川修司」と表記されることがある。
