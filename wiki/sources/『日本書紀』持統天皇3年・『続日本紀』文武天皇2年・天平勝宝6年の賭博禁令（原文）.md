# 『日本書紀』持統天皇3年・『続日本紀』文武天皇2年・天平勝宝6年の賭博禁令（原文）

ヤクザの起源説のうち、博徒の系譜を古代の賭博禁令に遡らせる説（尾佐竹猛・岩井弘融）が挙げる禁令を、官撰史書の刊本の画像で照合したノートである。論者のあいだで食い違っていた年次を確定できた。

## 書誌情報

- 『日本書紀』巻第三十 持統天皇3年12月丙辰条: 慶長15年（1610年）刊の古活字版（NDL ID 2544354）、コマ13。文政3年刊本（NDL ID 2599716）でも確認。
- 『続日本紀』巻第一 文武天皇2年7月乙丑条: 元禄4年（1691年）刊本（NDL ID 2546865）、コマ7〜8。
- 『続日本紀』巻第十九 天平勝宝6年10月乙亥条: 伴信友校の1883年刊本（NDL ID 772185）、コマ107。
- 所在は NDL ラボ「次世代デジタルライブラリー」の全文検索で特定し、IIIF 画像で判読した。

## 主要な論点

- 持統天皇3年（689年）12月丙辰（8日）条は「禁斷雙六」の一句のみである。直後に「四年春正月戊寅朔」が続くことで年次を確認した。
- 『続日本紀』の「禁博戲遊手之徒其居停主人亦與居同罪」は、文武天皇2年（698年）7月乙丑（7日）条にある。逃亡した奴婢を匿う者への笞法の制定と同じ条に置かれ、賭博をして定職に就かない者と、それを泊めた家の主人を同罪とする。
- 天平勝宝6年（754年）10月乙亥の勅は、官人・百姓が「私に徒衆を聚めて意に任せて雙六」することを禁じ、六位以下は男女を問わず杖一百、五位は解任・位禄位田の没収、四位以上は封戸の停止、黙認した国司・郡司は解任とし、20人以上を告発した者に叙位・賜物を与える。

## 新たに得られた事実

- Hill（岩井弘融に依拠）の「689年の賭博禁令」は、『日本書紀』の持統天皇3年12月の双六禁断と一致する。
- 尾佐竹猛（1925年）が「文武天皇元年の詔」とする条は、刊本の配列では文武天皇2年（698年）7月の記事である。江戸後期の考証随筆にも「元年」とする例があり、誤りは尾佐竹以前から流布していた可能性がある（raw ノートの推測）。
- 尾佐竹の「天平勝宝6年」の双六禁断は、原典の年次と一致する。

## 既存 wiki との矛盾・補強

- [[ヤクザの起源説]]で `[!question]` としていた「古代の禁令の年次の食い違い」を解消する。689年と698年と754年は別々の禁令であり、論者が別の禁令を挙げていたことが食い違いの原因である。尾佐竹の「元年」は1年の誤りである。
- 754年の勅は「私に徒衆を聚めて」双六をすることを問題にしているが、罰の対象は個々の官人・百姓であり、賭博を業とする集団の存在を示すものではない。博徒の集団化を江戸中期以降とする[[コトバンク 博徒・香具師・町奴の項|コトバンク]]の説明と矛盾しない。

## ソースの偏り・限界

> [!bias]
> 官撰史書の記事であり、禁令が出された事実の記録として信頼度は高い。ただし、禁令の実施状況や、賭博をする人々の実態は記されていない。刊本と『新訂増補国史大系』などの校訂本文との校合はしていない。
