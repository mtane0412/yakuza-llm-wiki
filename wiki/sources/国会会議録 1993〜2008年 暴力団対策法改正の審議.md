# 国会会議録 1993〜2008年 暴力団対策法改正の審議

[[暴力団対策法]]の1993年・1997年・2004年・2008年の4回の改正について、国家公安委員会委員長の提案理由説明と、委員長による審査経過の報告を、国会会議録検索システムの API から原文で取得した。国会での発言であり、改正の趣旨と内容を政府自身が説明した一次資料である。2012年改正は[[国会会議録 平成24年 暴力団対策法改正の審議]]を参照。

## 書誌情報

- 1993年: 第126回国会。村田敬次郎国家公安委員会委員長の提案理由説明（衆院地方行政委 1993年3月25日、参院地方行政委 4月8日）、衆院本会議の委員長報告（4月8日、中馬弘毅）、参院本会議の委員長報告（4月28日、佐藤三吾）。
- 1997年: 第140回国会。白川勝彦国家公安委員会委員長の提案理由説明（衆院地方行政委 1997年5月8日、参院地方行政委 5月27日）、衆院本会議の委員長報告（5月15日、穂積良行）、参院地方行政委の附帯決議案（5月29日、小林元）、参院本会議の委員長報告（5月30日、峰崎直樹）。
- 2004年: 第159回国会。小野清子国家公安委員会委員長の提案理由説明（衆院内閣委 2004年4月7日）と審議冒頭の発言（4月9日）、衆院本会議の委員長報告（4月13日、山本公一）、参院本会議の委員長報告（4月21日、簗瀬進）。
- 2008年: 第169回国会（参議院先議）。泉信也国家公安委員会委員長の提案理由説明（参院内閣委 2008年4月15日）、参院本会議の委員長報告（4月18日、岡田広）、衆院本会議の委員長報告（4月30日、中野清）。
- 発言ごとの ID と URL は raw に記載した。

## 主要な論点

- **1993年改正**: 暴対法施行後に暴力団員の組織離脱の傾向が見られることを踏まえ、(1) 指定暴力団員が他の指定暴力団員に指詰めを強要すること、少年に入れ墨を強要することなどを禁止し、(2) 人を威迫して密接関係者を加入させ、または脱退を妨害する行為を禁止して加入強要の規制を強化し、(3) 公安委員会が離脱希望者の離脱と社会経済活動への参加のための措置と、援護の啓発活動を行うこととし、(4) 競売・倒産整理や証券取引に介入する実態から、競売の対象となる土地・建物の明渡し料名目の不当要求、株式会社への株式の買取り等の要求などを暴力的要求行為に追加し、何人も暴力的要求行為の現場に立ち会って助けてはならないこととした。施行は公布から3月以内の政令で定める日とされた。（村田国家公安委員会委員長、1993-03-25）
- 1993年の衆院地方行政委の質疑では、法施行後の効果、警察庁重点取締り三団体の寡占化傾向への措置、離脱希望者の援護措置の具体的内容、暴力団の不正利益剥奪制度の創設の必要性などが取り上げられた。（中馬弘毅委員長報告、1993-04-08）
- **1997年改正**: 施行から5年余りで、みかじめ料の徴収など指定暴力団の業務に関し暴力的要求行為が繰り返される例や、準構成員など指定暴力団の影響下にある者が威力を背景に不当要求をする例が多いことから、(1) 業務に関し暴力的要求行為が繰り返されるおそれがあるとき、公安委員会が代表者等の上位の指定暴力団員に防止のための事項を命じられるようにし、(2) 指定暴力団員が準構成員や元組員などの第三者に準暴力的要求行為を要求・依頼・そそのかすこと、および威力を示すことを容認された者による準暴力的要求行為を禁止し、(3) 同一の指定暴力団内の集団相互の対立抗争（内部抗争）でも事務所の使用制限をできるようにし、(4) 報酬を得て粗野・乱暴な言動を交えて債務の履行を求める債権取立てを暴力的要求行為に追加した。別表に建設業法等の罪を追加した。施行は公布から6月以内の政令で定める日とされた。（白川国家公安委員会委員長、1997-05-08。穂積良行委員長報告、1997-05-15）
- 1997年の参議院の附帯決議は、人権侵害につながらない運用、偽装暴力団化の防止、不正収益の剥奪と被害回復の法的仕組みの速やかな検討、来日外国人組織による犯罪など組織犯罪の国際化・高度情報化への対応を求めた。（小林元、1997-05-29）
- **2004年改正**: 指定暴力団の代表者等は、指定暴力団相互間または内部の対立が生じ、指定暴力団員が凶器を使用した暴力行為で他人の生命・身体・財産を侵害したとき、その損害を賠償する責任を負うこととし、略取・誘拐の罪や出入国管理及び難民認定法の罪などを暴力的不法行為等の別表に追加した。施行は一部を除き公布の日とされた。小野国家公安委員会委員長は、実行行為者だけでなく代表者等の責任を追及することで、巻き添え被害の救済を容易にし、対立抗争の抑止にも資すると述べた。（小野国家公安委員会委員長、2004-04-07・04-09）
- **2008年改正**: (1) 指定暴力団員が威力を利用して行った資金獲得行為で他人の生命・身体・財産を侵害したとき、代表者等が一定の場合を除き損害賠償責任を負う、(2) 対立抗争に係る暴力行為の賞揚等を目的とする指定暴力団員への金品等の供与を公安委員会が禁止命令できる、(3) 指定暴力団員による不法行為の被害者の損害賠償請求等への妨害を禁止する、(4) 行政庁に許認可等を要求する行為等を暴力的要求行為に追加する、(5) 国・地方公共団体が民間の暴力排除活動を促進する措置を講じる、の5点である。施行は、(1)と(5)が公布の日、それ以外は公布から3月以内の政令で定める日とされた。（泉国家公安委員会委員長、2008-04-15）
- いずれの改正案も、委員長報告によれば両院の委員会で全会一致により原案どおり可決された。

## 新たに得られた事実

- 1993・1997・2004・2008年の各改正の内容が、政府の提案理由説明として原文で確認できた。これまで本 wiki では1993・1997年改正の内容が未確認だった。
- 各改正の審議日程（付託・提案理由・委員会採決・本会議）と、いずれも全会一致だったこと。
- 1993年改正で暴力的要求行為の現場への「立会い」の禁止（何人も）が加わり、1997年改正で準暴力的要求行為の規制が始まったこと。準暴力的要求行為は、2012年改正で離脱後5年以内の者に対象が広がる（[[国会会議録 平成24年 暴力団対策法改正の審議]]）。

## 既存 wiki との矛盾・補強

- [[警察白書 平成27年版 組織犯罪対策の歩みと展望|警察白書H27]]の「2004・2008年改正で代表者等の損害賠償責任」「2008・2012年改正で暴力的要求行為の追加」という整理を補強する。ただし、暴力的要求行為の類型の追加は1993年・1997年改正でも行われており、白書H27の整理は網羅的ではない（[[警察白書 平成6〜24年版 暴力団対策法の改正・指定状況・争訟|白書 平成24年版 図3-4]]も1993・1997年改正の類型追加を記す）。
- 2004年改正の施行日は、提案理由説明の「一部を除き、公布の日」と、改正法附則・平成16年版白書により、2004年4月28日と確認できた（[[暴力団対策法 改正法の附則（e-Gov）]]）。

## ソースの偏り・限界

> [!bias]
> 提案理由説明は政府の立場からの説明であり、改正の必要性を前提としている。委員会での質疑の詳細（議員の懸念や反対論）は、委員長報告の要約の範囲でしか収録していない。審議はいずれも全会一致で、会議録の要約からは少数意見を読み取りにくい。
