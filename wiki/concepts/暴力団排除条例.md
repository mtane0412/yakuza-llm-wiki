# 暴力団排除条例

都道府県が制定する、暴力団の排除を目的とした条例である。暴力団の威力を利用する目的での利益供与の禁止や、暴力団事務所の開設・運営の禁止などを定める。[[警察白書 令和8年版 第4章 組織犯罪対策|警察白書 令和8年版]]（第1節3(4)）

## 制度の内容

- 暴力団の威力を利用する目的での利益供与の禁止、暴力団事務所の開設・運営の禁止などを定める。[[警察白書 令和8年版 第4章 組織犯罪対策|警察白書 令和8年版]]
- 令和7年（2025年）中の実施件数は、勧告36件、指導2件、中止命令2件、再発防止命令2件、検挙26件である。同上
- 基本的施策、青少年への悪影響排除、暴力団の利益になる行為の禁止などが主な内容である。[[警察白書 平成25年版 暴力団対策|警察白書 平成25年版]]

- 福岡県条例（2010年4月1日施行）は、事業者が、暴力団の威力を利用する目的で、または利用したことに関し、暴力団員等へ利益を供与することを禁止する。暴力団の活動・運営に協力する目的での相当の対償のない利益供与、情を知って暴力団の活動を助長する利益供与も禁止され、違反は1年以下の懲役または50万円以下の罰金である。取引の相手方が暴力団員でないことの確認は努力義務である。[[暴力団排除条例の条文（福岡県2010年・東京都2011年）|福岡県条例]]（第15〜18条・第25条）
- 東京都条例（2011年10月1日施行）第24条は、事業者が暴力的不法行為等の対償として、または暴力団の活動を助長し運営に資することを知って、規制対象者に利益供与をすることを禁止する。規制対象者が情を知って利益供与を受けることも禁止する。[[暴力団排除条例の条文（福岡県2010年・東京都2011年）|東京都条例]]（第24条・附則）
- 全都道府県での施行は、「平成23年10月までに」完了した。[[警察白書 平成25年版 暴力団対策|警察白書 平成25年版]]（第3章第1節4 コラム③）2012年中の実施件数は、勧告68件、指導3件、中止命令6件、検挙5件である。同上

- 愛知県条例（2010年10月15日公布、2011年4月1日施行）と大阪府条例（2010年11月4日公布、2011年4月1日施行）、宮城県条例（2011年4月1日施行）、青森県条例（2011年3月25日公布、2011年7月1日施行）の条文を確認した。[[元暴5年規定の条文（暴対法・業法・暴排条例・全銀協参考例）|元暴5年規定の条文]]
- 警察庁が犯罪対策閣僚会議（第18回、2011年）に出した資料は、「全都道府県において、平成23年７月までに暴力団排除に関する条例を制定」と記す。同上 制定（2011年7月まで）と施行（2011年10月まで）の時期は区別される。

### 「暴力団員等」の定義の違い

条例が誰を規制の対象とするかは、都道府県によって異なる。[[元暴5年規定の条文（暴対法・業法・暴排条例・全銀協参考例）|元暴5年規定の条文]]

| 条例 | 施行 | 定義 |
|------|------|------|
| 福岡県 | 2010年4月1日 | 第2条第3号「暴力団員等 暴力団員又は暴力団員でなくなった日から５年を経過しない者」 |
| 愛知県 | 2011年4月1日 | 第2条第3号 同旨 |
| 大阪府 | 2011年4月1日 | 第2条第3号 同旨。第4号で「暴力団密接関係者」を公安委員会規則に委ねる |
| 宮城県 | 2011年4月1日 | 第2条第4号 暴力団員、離脱後5年の者、それらを役員に含む法人等 |
| 青森県 | 2011年7月1日 | 「暴力団員等」の定義なし |
| 福島県 | 2011年7月1日（2011年3月18日公布、条例第51号） | 第2条第3号「暴力団員又は暴力団員でなくなった日から５年を経過しない者（公安委員会規則で定める者を除く。）」（2018年改正後の条文で確認）[[岩手・秋田・山形・福島の暴力団排除条例の施行日と定義\|東北4県の暴排条例]] |
| 秋田県 | 2011年3月14日（一部は同年7月1日） | 未確認（リーフレットの表紙のみ確認）。同上 |
| 山形県 | 2011年8月1日 | 未確認（リーフレットの表紙のみ確認）。同上 |
| 東京都 | 2011年10月1日 | 「暴力団関係者」（暴力団員又は暴力団・暴力団員と密接な関係を有する者）と「規制対象者」を定義。離脱後5年の者は含まない |

> [!question] 要出典
> 上記以外の38道府県の条例の条文・制定年は確認していない（岩手県は、2010年9〜10月に条例案の基本的考え方の意見募集をしたことまでを確認した）。警察庁が都道府県ごとの制定・施行日を一覧にした資料も見つからなかった。

## 起源と変遷

- 条例を用いた暴力団対策は、昭和30年代の愚連隊防止条例にも先例がある。昭和37年東京都の条例を皮切りに、40年ころまでに多数の自治体で愚連隊防止条例が制定された。[[平成元年警察白書 第1節 暴力団の変遷と最近の特徴|平成元年警察白書]]。ただし、これは暴力団排除条例の直接の前身かは本 wiki のソースでは未確認で、別の制度である。
- 福岡県が条例を全国に先駆けて施行した背景として、福岡県警の担当官は、暴力団の存在が県民の安全で平穏な生活の大きな脅威となっていたと述べる。[[警察政策フォーラム 暴力団員の社会復帰対策（2017）|警察政策フォーラム]]（持丸講演、p.93）北九州市長も、2010年3月の施行直前に市内の学校近くで暴力団が組名の看板を掲げて事務所を設置したと国会で述べた。[[国会会議録 平成24年 暴力団対策法改正の審議|国会会議録]]（2012-06-19）
- 2007年6月19日の政府指針は、企業に取引を含む一切の関係遮断を求め、暴力団排除を民間の責務として位置づけた。[[企業が反社会的勢力による被害を防止するための指針|企業指針]]。この動きが条例の整備につながったと時代ページは整理するが、因果関係はソースで確認できていない。

## 論点・解釈の違い

- 離脱後5年間の「元暴5年」規定が離脱者の口座開設・就労の障壁になるとの指摘がある。福岡県警の担当官は、更生を支援する観点から改善が必要だと述べた。[[警察政策フォーラム 暴力団員の社会復帰対策（2017）|警察政策フォーラム]] 5年の根拠は、福岡県など一部の条例の定義のほか、業法の欠格事由、銀行など業界の暴排条項（全銀協の参考例は2011年6月改正で追加）、暴対法第12条の5にもあり、条例だけに由来するものではない。[[元暴5年規定の条文（暴対法・業法・暴排条例・全銀協参考例）|元暴5年規定の条文]]、[[元暴力団員の社会復帰（5年ルール）]]
- 構成員・準構成員等の総数は2016年末の39,100人から2025年末の17,600人へと半分以下になった。白書は背景に「集中的な取締り」と「暴力団排除の取組の進展による構成員の離脱」を挙げる。[[警察白書 令和8年版 第4章 組織犯罪対策|警察白書 令和8年版]]（第1節1(1)）
- 条例の効果と構成員減少の因果は、ソースからは切り分けられない。

> [!bias]
> 警察庁の公式文書であり、離脱者の社会復帰が実際にどこまで進んだかは書かれていない。排除の副作用への批判的見解は、研究者（廣末登）の発表に限られる。[[警察政策フォーラム 暴力団員の社会復帰対策（2017）|警察政策フォーラム]]
